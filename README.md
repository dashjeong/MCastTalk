# MCastTalk

**실시간 다국어 통역방송(feat. DMZ peace walk)**

Android에서 음성을 통번역하고, 같은 Wi-Fi 또는 핫스팟의 청취자에게 음성과 자막을 전달하는 앱입니다. 청취자는 별도 앱 없이 웹브라우저로 접속합니다. 기기 단독 사용, 음성노트, 파일 변환·재생을 지원합니다.

**0.2.50-beta** · versionCode **62** · 제한된 기능 프리뷰

[프리뷰 APK 다운로드](https://github.com/dashjeong/MCastTalk/releases/tag/v0.2.50-beta) · [한국어 사용 안내](docs/USER_GUIDE_KO.md) · [English guide](docs/USER_GUIDE_EN.md)

## 설치와 사용

- 송신기: Android 11(API 30) 이상, ARM64.
- 다운로드한 APK의 SHA-256을 릴리스의 체크섬 파일과 비교하세요. 업데이트 시 기존 앱과 배포 서명이 같아야 합니다.
- 사용할 언어를 선택하고 필요한 모델·음성을 먼저 준비합니다. 초기 다운로드에는 인터넷이 필요합니다.
- 기기 내 통역은 준비된 모델을 사용합니다. 온라인 API는 제공자·모델·키와 외부 전송 허용을 설정해야 하며 제공자 요금이 발생할 수 있습니다.

## 통역 방식과 청취

- **문장 통번역**: 기기에서 음성을 인식하고, 선택한 온라인 문장 모델로 번역한 뒤 기기 음성으로 재생합니다. 오프라인 모델도 선택할 수 있습니다.
- **통역 중계**: Gemini Live 또는 OpenAI Realtime 음성 서비스를 선택합니다. 발화 언어와 최대 5개 통역 언어를 지정하며 언어마다 별도 연결과 API 비용이 발생합니다. 휴대폰에서는 선택한 1개 언어를 듣고, LAN 청취자는 송출 중인 언어를 각각 선택합니다.
- 모델 선택은 통역 방식별로 구분됩니다. 선택한 모델이 지원하는 목소리·전문 문맥 옵션을 확인하고 방송을 시작하세요.
- 통역 중계는 방송 제목을 입력하고 **방송 시작**을 누른 뒤 **마이크 켜기**로 통역을 시작합니다. 방송 송출과 마이크는 따로 조작합니다. 송출 일시정지 중 마이크가 켜져 있으면 기기 통역·녹음은 이어지고, 재개 후 기록이 공유됩니다.
- LAN 청취자 방송을 켜고 방송을 시작하면 청취 주소와 QR이 표시되며 방송 중에도 확인할 수 있습니다. 청취자는 같은 Wi-Fi 또는 핫스팟에서 접속해 언어를 고르고 **듣기 시작**을 누릅니다. 다른 네트워크로 인터넷 방송하려면 별도 네트워크 구성이 필요합니다.
- 같은 방송에서 마이크를 껐다 켜거나 송출을 재개해도 청취 주소와 접속 권한을 유지합니다. 방송 종료 후 새 방송은 새 접속 권한을 만듭니다. 화면에는 주소를 간단히 표시하고 QR·복사·공유에는 접속 권한을 포함합니다.
- 원문 자막 아래에 통역문을 모아 표시하며, **통역 언어**에서 전체·개별 표시를 선택합니다. 입력이 같은지 확인되지 않은 독립 자막은 구분해서 표시합니다.
- **입력 설정**에서 마이크별 소음 처리와 가까운 화자 중심을 선택합니다. 처리 끄기는 마이크 끄기와 구분됩니다. 기기의 실제 지원 상태와 입력 레벨을 확인하세요. 소음 처리는 화자를 구분하는 기능이 아닙니다. 가까운 화자 중심은 지원 기기에 방향·집중 처리를 요청하며, 미지원 시 기본 마이크 입력을 유지합니다. 이어폰이나 화자 가까이에 둔 외부 마이크를 사용하세요.
- 웹 청취 페이지의 **HUD 보기**에서 원문·선택 번역을 크게 볼 수 있습니다. **HUD 닫기** 또는 뒤로가기로 원래 화면에 돌아갑니다. HUD 표시와 주소·QR 및 방송 환경 설정은 각각 구분됩니다.

## 제공 기능

- 로컬 E2B/E4B 모델 선택, 온라인 API와 언어별 음성·자막.
- 방송별 문맥 참고, 전문분야·지시문·참고 자료, 검토 후 활성화하는 로컬 교정 기록.
- 방송 제목·이력 이름 변경, 목록의 **선택** 또는 **3초 누르기**를 통한 선택 삭제. 진행 중인 방송은 삭제할 수 없습니다.
- 방송 이력의 스크립트 조회·음성 재생, MP3 음성과 텍스트 스크립트 내보내기·공유.
- 청취 페이지의 실시간 듣기와 저장된 방송 돌려보기.
- 음성노트의 원음·원문·번역 보관, 편집, 재생, 백업·가져오기.
- 파일 통번역·재생, 사용자 사전과 설정 이관.

지원 언어·동시 처리 성능·사용할 수 있는 옵션은 선택한 인식·번역·음성 엔진, 설치 자산과 기기에 따라 다릅니다.

## 프리뷰 제한

기능 확인을 위한 프리뷰이며 음성인식 오류, 번역 오류, 연결 중단과 지연이 발생할 수 있습니다. 실제 마이크 통역·LAN 음성 전달·연속 운영·전문분야 품질 개선은 최종 확인 전입니다. 모든 언어·기기의 정확도, 장시간 연속 운영과 사람 수준의 통역 품질을 보증하지 않습니다. 온라인 중계의 언어 수가 늘면 네트워크·처리량과 제공자 요금이 증가합니다. 러시아어 오프라인 음성에는 호환되는 음성 데이터가 필요합니다. HTTP 청취 방송은 암호화되지 않으므로 신뢰할 수 있는 네트워크에서 사용하세요. 이전 버전으로 되돌리기 전에 데이터를 백업하세요.

## 소스와 라이선스

프리뷰 APK에 대응하는 소스는 `v0.2.50-beta` 태그에서 확인하세요. 빌드에는 JDK 17, Android SDK API 36과 Gradle 설정의 도구가 필요합니다.

```sh

./gradlew :app:assembleDebug
```
