# MCastTalk

Android에서 음성을 통번역하고, 접속 가능한 네트워크의 청취자에게 음성과 자막을 전달하는 앱입니다. 청취자는 별도 앱 없이 웹브라우저로 접속합니다.

[모바일 릴리스·APK 다운로드](https://github.com/dashjeong/MCastTalk/releases) · [한국어 사용 안내](docs/USER_GUIDE_KO.md) · [English guide](docs/USER_GUIDE_EN.md)

Windows x64 데스크톱은 [0.2.49-desktop 사전 공개판](https://github.com/dashjeong/MCastTalk/releases/tag/v0.2.49-desktop)으로 별도 제공됩니다. 설치 조건과 소스·실행파일 안내는 해당 릴리스를 확인하세요.

## 설치와 사용

Android 11(API 30) 이상 ARM64 기기에서 사용합니다. APK와 같은 릴리스의 `SHA256SUMS`를 확인한 뒤 설치하세요. 기존 Alpha 앱은 같은 앱 ID·서명의 APK로 업데이트합니다. Debug 앱은 별도 설치되며 데이터가 자동으로 이동하지 않습니다. 설치 충돌이 나면 삭제 전에 필요한 데이터를 내보내세요.

1. 통번역 스트리밍, 통역 중계, 음성 노트, 파일 변환·재생, 방송 이력에서 작업을 선택합니다.
2. **설정**에서 공통 환경을, 각 메뉴의 **이 메뉴 설정**에서 해당 작업의 환경을 준비합니다. 마이크 입력과 웹 방송은 각각 제어합니다.
3. 웹 방송을 시작하고 표시된 주소·QR을 청취자에게 공유합니다. 청취자는 접속 후 **듣기**를 누르고 음성·자막 언어를 선택합니다.

통역 중계에서는 발화 언어 1개와 통역 언어 최대 5개를 선택합니다. 검색 목록의 75개 언어·지역 선택지는 모든 모델의 지원·품질 보장을 뜻하지 않습니다. 통역 언어마다 별도 실시간 API 연결을 사용하므로 선택 수에 따라 비용이 늘어날 수 있습니다. 온라인·오프라인 비교에서 승인한 교정 사례는 지원되는 경로에서 참고하며, 모델 가중치를 다시 학습하지 않습니다.

온라인 기능은 API 키, 호환 모델, 인터넷 연결과 전송 동의가 필요하며 제공자 요금이 발생할 수 있습니다. 기기 내 통번역은 사용할 언어의 모델·음성을 준비해야 합니다. 모델과 API 키는 포함하지 않습니다. 지원 언어·음성·정확도·지연은 제공자, 설치 자산, 기기와 환경에 따라 달라집니다.

웹 방송은 휴대폰 서버에 접속 가능한 네트워크에서 이용합니다. 인터넷 공개 접속은 별도 네트워크 구성이 필요합니다. HTTP 방송은 암호화되지 않으므로 신뢰할 수 있는 네트워크에서 사용하세요. 저장 방송은 방송 이력에서 음성과 스크립트를 확인한 뒤 MP3/TXT를 내려받거나 공유합니다. 다시 듣기 HUD의 저장 스크립트는 음성과 자동으로 시간 동기화되지 않습니다.

## 소스 빌드와 라이선스

배포 APK와 연결된 버전·태그·소스 ZIP은 해당 릴리스에서 확인하세요. JDK 17과 Android SDK 36을 준비한 뒤 실행합니다.

```sh
./gradlew :app:assembleAlpha :app:verifyPackagedThirdPartyLicenseAssets
```

자신의 SDK 위치를 설정하세요. 개인 서명 설정이 없으면 서명되지 않은 Alpha APK가 생성되므로 설치·배포에는 자신의 서명이 필요합니다. APK 배포자의 서명 키는 포함하지 않습니다. Gradle Wrapper 8.13과 pinned 의존성 검증 파일을 사용합니다. 공공용어 고정 데이터·출처는 [용어 데이터 안내](docs/TERMINOLOGY_DATA.md)를 확인하세요.
