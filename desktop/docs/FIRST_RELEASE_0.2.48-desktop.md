# MCastTalk 0.2.48-desktop 1차 공개

2026-10-06 공개하는 Windows x64 데스크톱 **사전 공개판(prerelease)**입니다. 설치·환경 구성·화면·연계 기능을 먼저 공개하고, 실제 통역 음성의 7초 이내 전달과 300명 이상 운영은 후속 업데이트에서 시험하고 개선합니다.

## 실행파일과 첫 실행

GitHub Releases에서 Windows x64 EXE와 함께 제공되는 SHA-256 검증값을 내려받습니다. EXE는 약 10.8MB이며 관리 화면, 참여 웹 화면, 웹서버와 Go 실행 프로그램을 포함한 실제 Windows 실행파일입니다. Go나 Python을 따로 설치할 필요는 없습니다. 대형 AI 모델과 추론 런타임은 별도입니다.

1. EXE를 실행하고 **모델·PC 진단**에서 메모리·디스크·장치와 모델 후보를 확인합니다.
2. **환경 일괄 구성**에서 모델·런타임·용량·이용조건을 확인한 뒤 **필요 환경 받기·구성·구동 검증**을 선택합니다. 다운로드는 사용자가 선택해야 시작합니다. 이미 받은 파일은 가져올 수 있습니다.
3. 파일의 크기·SHA-256과 설치 내용을 확인한 뒤 엔진 기동, 전사·번역·언어별 음성합성을 시험합니다. 다운로드 성공만으로 준비 완료를 표시하지 않습니다.
4. 선택 언어의 모든 준비 시험을 통과한 다음 실제 문장을 입력하고 마이크·청취 시험을 진행합니다. 준비 시험이 실패한 환경에서는 통역 서비스를 시작하지 않습니다.

Windows 10 버전 1903 이상 또는 Windows 11을 대상으로 합니다. 1차 공개의 실제 Windows 시험 환경은 Windows 11 평가 VM입니다. 필요한 Microsoft VC++ 구성요소는 고정된 공식 설치파일의 해시·서명을 확인하고 일반 Windows 관리자 승인으로 설치합니다. GPU/NPU 감지 결과는 실제 가속 지원이나 속도 보장이 아닙니다.

## 제공하는 기능

- 공개 강의·공지와 개인 대화 채널, 강사·학생 역할을 구분한 QR 참여, 참여자별 언어 설정을 제공합니다. 같은 발화의 같은 대상 언어 결과를 공유하며 개인 채널 접근은 지정된 참여자로 제한합니다.
- 모델·추론 런타임 내려받기와 파일 가져오기, Hugging Face 모델 등록을 제공합니다. 등록한 모델은 대상 PC에서 실제 구동·통번역 시험을 통과해야 사용할 수 있습니다.
- 녹음·전사·번역·작업 상태를 저장하고 재실행 시 진행 중 작업을 복구합니다. PC가 꺼진 동안의 음성은 복구할 수 없으며 브라우저 마이크는 다시 켜야 합니다.
- 인터넷이 되는 PC에서 구성한 환경을 ZIP 또는 폴더로 내보내고 대상 PC에서 검사·가져올 수 있습니다. 모델·런타임·선택 자료를 옮기며 인증키·PIN·개인 대화·녹음은 환경 패키지에 포함하지 않습니다. 대상 PC의 OS·아키텍처·드라이버·LAN·HTTPS와 실제 오프라인 구동은 별도로 확인해야 합니다.

자세한 실행·네트워크·백업·환경 이전 절차는 [데스크톱 안내](../README.md)를 참고하세요.

## 확인한 결과와 현재 제한

최신 수정 소스는 안티그래비티 Gemini 고성능 모델과 교차검토했습니다. 제공한 소스 범위의 기동 대기·준비 상태 수정 후 재검토에서는 P0/P1 결함이 발견되지 않았습니다. 이는 전체 운영 품질이나 모든 요구사항의 완료 판정은 아닙니다.

| 시험 | 결과와 범위 |
| --- | --- |
| 최신 전체 Go 경합·회귀시험 | 통과, 97.189초 (공개 브랜치) |
| 기동·준비 상태 수정의 집중 시험 | 통과, 1.574초 |
| Windows 정적 검사·EXE 빌드·실제 PE 매니페스트 검사 | 통과 |
| 관리 화면 시험 | 이전 소스의 실제 서버와 시험용 모델·장치·마이크 조건에서 24개 통과 |
| Windows 다국어 경로의 음성합성 | 이전 실행파일 C5에서 한국어·영어·일본어·중국어·스페인어 각 2회, 총 10회 통과. 전사·번역을 포함한 종단 시험은 아님 |
| Windows 통합 환경 구성 | 이전 실행파일 C6에서 모델·런타임 7개 가져오기 성공. 이후 Whisper 준비 시험 시간 초과로 전체 준비 실패 |
| 최신 수정 실행파일 C7의 실제 Windows 통합 재시험 | 미완료 |

Windows 통합 실패에서는 엔진 기동·모델 로드 단계가 약 182초 소요됐고, 읽기 전용 진단으로 Whisper 준비 시험 시간 초과를 확인했습니다. 시간 초과의 직접 원인과 세부 단계별 소요시간은 아직 확정하지 않았습니다. C7은 모델 프로세스가 종료되면 준비 대기를 즉시 끝내고, 번역 준비 시험 실패를 성공으로 표시하지 않도록 수정했습니다. 이 수정이 해당 Windows 시간 초과를 해결했다고 판정하지 않습니다.

따라서 이 공개판은 실제 문장·청취 정확도, 마이크 입력부터 상대방의 첫 통역 음성까지 7초 이내 전달, 300명 이상 모델 처리, GPU/NPU 가속 성능, 8시간 연속 운영을 인증한 버전이 아닙니다. 인터넷을 OS 수준에서 차단한 대상 PC의 전체 환경 이전·운영과 갑작스러운 전원 중단 중 서비스 연속성도 추가 시험 대상입니다. 모바일 OpenAI·Gemini 통역 지연은 실제 스마트폰 로그와 공급자별 실행 결과로 별도 진단해야 합니다.

## 후속 업데이트의 시험 순서

1. **Windows 준비 실패 진단:** Whisper 프로세스 시작·모델 로드·준비 응답·시험 전사를 따로 측정합니다. 대상 PC에서 가능한 작은 CPU 모델과 설정을 비교하고, 준비 시험을 통과한 조합만 안내합니다. C7의 실제 Windows 재시험 결과를 기록합니다.
2. **7초 지연과 정확도:** 실제 마이크 입력부터 상대방이 듣는 첫 통역 음성까지 측정하고 전사·번역·합성·전송·재생 시간을 함께 기록합니다. OpenAI와 Gemini 각각의 실제 모바일 로그를 비교합니다. 5개 이상 언어의 의미·맥락·용어·발음·대화 차례를 사람이 듣고 평가합니다.
3. **30명 → 100명 → 300명 이상:** 실제 모델을 사용해 언어 수와 동시 발화자 수를 명시하고 확장합니다. 전체 공지의 언어별 공유와 개인 대화의 트래픽·접근·맥락 격리를 함께 확인합니다. 동시 접속 시험을 동시 발화 처리 성능으로 표시하지 않습니다.
4. **연속 운영과 복구:** 8시간 이상 운영, 혼잡·네트워크 단절·엔진 실패·강제 종료·갑작스러운 재부팅을 반복합니다. 저장 자료의 최신성, 중복·누락, 재접속, 작업 재개, 개인정보 노출 여부를 검사하고 수정 후 같은 조건으로 재시험합니다.
5. **오프라인·장치 호환성:** 검증한 환경을 별도 Windows PC로 옮겨 인터넷 차단 상태에서 시험합니다. NVIDIA·AMD·지원 NPU의 실제 런타임·모델 조합을 각각 검증합니다. 모바일에도 적용할 수 있는 개선 사항은 별도 발전 기록으로 남깁니다.

후속 릴리스에서는 통과한 시험 조건과 남은 제한을 함께 공개합니다. 모바일과 구분해 `-desktop` 버전을 계속 관리합니다.
