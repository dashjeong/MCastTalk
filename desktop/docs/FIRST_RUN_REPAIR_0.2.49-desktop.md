# MCastTalk 0.2.49-desktop 첫 실행 복구 — 공개 준비안

**게시 보류:** 이 문서는 새 Windows x64 사전 공개판의 안내 초안입니다. 새 시험 후보는 실제 Windows에서 파일 준비를 마쳤지만, 이후 음성 모델 로드 단계가 실패했습니다. 전체 구성의 22개 확인을 통과하지 못했으므로 0.2.49를 게시하지 않습니다. 원인을 진단하고 수정한 새 소스·실행파일을 다시 확인해야 합니다. 현재 공개된 [0.2.48-desktop](https://github.com/dashjeong/MCastTalk/releases/tag/v0.2.48-desktop)은 기존 기록과 실행파일을 그대로 보존합니다.

0.2.48은 파일을 받은 뒤 실제 모델 준비 단계에서 진행할 수 없는 문제가 확인됐습니다. 0.2.49는 파일을 먼저 준비하는 경로, 다운로드 복구와 CPU 첫 실행 구성을 개선합니다. 실제 음성인식·번역·음성 출력의 전체 연결은 새 실행파일로 별도 확인해야 합니다.

## 첫 실행

관리 화면은 Open WebUI에 익숙한 사용자가 따라가기 쉽도록 왼쪽 메뉴와 중앙 작업 화면, 다음 네 단계를 사용합니다.

1. **PC 확인:** 모델·PC 진단에서 저장 공간, 실행에 필요한 여유 RAM과 Windows 실행 구성요소 상태를 확인합니다. 필요한 RAM이 부족하거나 Windows 실행 기반 확인이 끝나지 않아도 Windows x64와 저장 공간 조건이 맞으면 파일을 먼저 준비할 수 있습니다.
2. **파일 준비:** 번역·음성인식·음성 모델, 실행 엔진의 용량과 이용조건을 확인하고 동의한 뒤 준비를 시작합니다. 이미 검증한 파일은 재사용합니다. **파일 먼저 준비**는 Windows 구성요소를 설치하거나 UAC 승인을 요청하지 않습니다.
3. **실제 통역 확인:** 파일이 준비되면 대상 PC의 RAM·Windows 실행 조건을 다시 확인하고 **저장된 환경 구동 확인**을 실행합니다. 필요한 Microsoft 구성요소의 실제 설치는 이 단계에서 공식 설치파일의 서명을 확인하고 정상 UAC 승인을 받아 진행합니다. 재부팅 필요·승인 거절·설치 진행 중·구동 실패는 완료가 아닙니다.
4. **사용 시작:** 선택한 언어의 음성인식·번역·음성 출력 확인이 모두 통과한 뒤 강의실 또는 음성노트를 엽니다. 실제 문장·마이크·청취 시험으로 의미 정확도와 지연을 확인합니다.

**파일 준비 완료**는 실제 모델이 실행됐다는 뜻이 아닙니다. 받은 환경은 다른 PC로 내보낼 수 있지만, 대상 PC의 설치·실행·품질 판정은 따로 확인합니다. 준비 실패 후에는 받은 파일을 유지하고 **PC 다시 확인** 또는 **저장된 파일로 이어서 준비**를 이용합니다. [전체 사용·오프라인 이전 안내](../README.md)를 참고하세요.

## 바뀐 준비 동작

- 파일 준비 가능 여부와 실제 실행 가능 여부를 각각 표시합니다. 실측 Windows x64·디스크 조건은 파일 준비에 필요하고, 여유 RAM과 완료된 Windows 실행 기반 진단은 실제 구동에 필요합니다. 알 수 없는 네이티브 진단 결과를 준비 완료로 바꾸지 않습니다.
- HTTP 응답 헤더·TLS 협상 대기 제한과 **2분 네트워크 수신 유휴 제한**을 추가했습니다. 데이터가 계속 들어오는 정상 다운로드의 전체 소요시간에는 제한을 두지 않습니다. HTTP 오류 종류를 구분하고 일시적인 오류는 총 3회까지 시도하며, 지원하는 응답의 `Retry-After`를 제한된 대기 범위에서 반영합니다. 서버가 지원하고 범위 응답이 유효할 때 부분 파일을 이어받습니다. 크기·SHA-256·범위 오류를 재시도로 무시하지 않습니다.
- Microsoft VC++ x64 공식 고정 설치파일 약 18.7MB를 해시 검증 후 캐시할 수 있습니다. 파일 준비와 오프라인 가져오기는 설치파일을 보관하며 Windows를 설치·변경하지 않습니다. 실제 구동 확인 때 별도 서명 확인과 정상 UAC 설치를 거칩니다.
- 새 CPU 기본 음성인식 모델은 **Whisper Small (Q5)**입니다. whisper.cpp 배포 저장소의 고정 리비전에 있는 약 190MB 파일을 사용하며 SHA-256은 `ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb`입니다. 모델 자원 부담을 줄이는 시작 구성이며 정확도·7초 지연·강의 수용량을 보장하지 않습니다.
- 기존 CPU 설정의 Whisper Turbo 또는 Turbo Q5는 자동으로 바꾸지 않습니다. **CPU 시작용 음성인식 모델 선택**을 누르면 음성인식 모델만 Small Q5로 바꾸며 현재 번역 모델과 CPU 설정을 유지합니다. 다른 가속 설정이나 사용자가 고른 다른 모델은 이 안내의 전환 대상이 아닙니다.
- 엔진 시작의 음성 파일 검사·모델 로드·첫 추론 단계와 소요시간을 기록합니다. 진행 표시와 파일 준비/실행 결과를 구분하며, 구동을 기다리는 동안 모델 선택을 막습니다.

## 사전 공개의 한계

22개 준비 확인은 로컬 음성 파일, CPU 엔진 기동, 입력 시험 음성과 WAV 음성인식, 5언어 번역·음성합성, 4개 참여자 언어의 WAV 음성인식·역방향 번역의 연결을 확인합니다. 결과가 존재하는지 확인하는 기능 시험이며 사람이 평가한 인식·번역·발음 품질을 증명하지 않습니다.

실제 마이크 입력부터 청취자 출력까지 7초 이내 지연, 30·100·300명 이상 운영, 장시간 실행, GPU/NPU 성능과 사람 수준의 통역 품질은 이번 사전 공개의 완료 범위가 아닙니다. 새 실제 Windows 구동 확인에 성공해도 이 항목들은 미검증으로 유지합니다. 개인 음성·원문·로그·API 키는 공개 문제 신고에 첨부하지 마세요.

[모바일로 이어갈 개선 후보](MOBILE_EVOLUTION_FROM_FIRST_RUN_REPAIR.md)는 별도 기기 검증이 필요한 설계 기록입니다.
