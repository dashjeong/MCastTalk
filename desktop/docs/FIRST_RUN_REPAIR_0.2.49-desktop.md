# MCastTalk 0.2.49-desktop 첫 실행 준비와 복구

모델을 받은 뒤 실행할 수 없었던 문제를 조사하며 파일 준비와 실제 구동 확인을 분리했습니다. 현재 후보는 실제 Windows CPU 환경에서 공식 파일을 새로 준비한 뒤 별도 구동 작업의 22개 기능 연결 확인을 통과했습니다. 파일 준비와 실제 구동 상태를 각각 확인한 다음 방송이나 음성노트를 시작하세요. 이전 공개 [0.2.48-desktop](https://github.com/dashjeong/MCastTalk/releases/tag/v0.2.48-desktop)의 기록과 실행파일은 보존합니다.

## 시작 준비 네 단계

1. **PC 확인:** 모델·PC 진단에서 Windows x64, 저장 공간과 여유 RAM을 확인합니다. RAM이나 실행 기반 진단이 완료되지 않아도 파일 준비 조건이 맞으면 **파일 먼저 준비**를 사용할 수 있습니다.
2. **파일 준비:** 용량과 이용조건을 확인하고 동의한 뒤 준비합니다. 검증된 파일을 재사용하며, 서버가 지원하고 범위 응답이 유효하면 부분 파일을 이어받습니다. Microsoft 구성요소 설치파일은 해시를 확인해 캐시하고 이 단계에서는 설치하지 않습니다.
3. **구동 확인:** 대상 PC의 실행 조건을 다시 확인하고 **저장된 환경 구동 확인**을 실행합니다. 필요한 구성요소는 공식 서명 확인과 정상 Windows UAC 절차를 거칩니다. 재부팅 필요·설치 진행 중·실패는 완료가 아닙니다.
4. **사용 시작:** 선택 언어의 음성인식·번역·음성 출력 확인이 모두 성공하면 방송 또는 음성노트를 엽니다. 참여 주소·QR을 안내하고 실제 마이크·문장·청취로 품질과 지연을 확인합니다.

**파일 준비 완료**는 모델 실행 성공을 뜻하지 않습니다. 다른 PC로 옮겼다면 대상에서 다시 진단·구동 확인해야 합니다. [전체 사용·오프라인 이전 안내](../README.md)를 참고하세요.

## 중단됐을 때

- 받은 파일을 유지한 채 **PC 다시 확인** 또는 **저장된 파일로 이어서 준비**를 사용합니다. 크기·해시·이어받기 범위가 맞지 않으면 해당 파일을 완료로 처리하지 않습니다.
- 진행 화면에서 파일 검사·모델 로드·첫 추론 단계와 경과시간을 확인합니다. 구동 중에는 모델 선택을 바꿀 수 없으며 실패한 단계는 완료와 구분합니다.
- 다운로드는 HTTP 응답 헤더·TLS 대기와 2분 수신 유휴 제한을 사용합니다. 데이터가 계속 들어오는 다운로드의 전체 시간은 제한하지 않습니다. 일시적 오류는 제한된 재시도를 하고 지원하는 `Retry-After`를 반영합니다.
- 기존 CPU의 Turbo/Turbo Q5는 자동 변경하지 않습니다. **CPU 시작용 음성인식 모델 선택**을 누르면 약 190MB의 Whisper Small (Q5)로 음성인식 모델만 바꾸고 번역 모델·CPU 설정은 유지합니다.

## 확인 범위

현재 실행파일의 실제 Windows CPU 시험은 두 경로를 확인했습니다. 저장된 환경에서는 22개 고유 확인을 통과했습니다. 별도의 새 환경에서는 공식 모델·런타임 7개가 모두 없는 상태에서 다운로드와 Microsoft 설치 캐시를 준비한 뒤, 다른 구동 작업에서 CPU 번역·음성인식·음성 출력과 22개 확인을 통과했습니다. 새 환경 전체 소요시간은 약 8분 45초였으며 준비와 구동을 합친 측정값입니다. 각각 원본 54개와 173개 및 해시 영수증을 독립 재판정했습니다.

시작 중·세 엔진 준비 완료·시험 종료의 세 화면에서 모델 콘솔이 앞으로 나오지 않았습니다. 이 관찰은 세 시점에 한정합니다. 관리 화면 19개 Chrome 흐름은 fixture를 포함한 시험이며 실제 모델 구동 판정과 구분합니다. 다른 PC·가속기·연속 동작과 이전 실패의 정확한 원인이나 근본 해결은 이 결과로 보장하지 않습니다.

22개 확인은 고정 합성 WAV의 비어 있지 않은 결과와 합성 음성의 연결을 확인하며 사람이 평가한 인식·번역·발음 품질을 증명하지 않습니다. 실제 마이크부터 청취자까지 7초 지연, 300명·장기·가속기 성능은 미검증으로 유지합니다. 개인 음성·원문·설정·로그·키는 공개 문제 신고에 첨부하지 마세요.

화면 흐름은 [Open WebUI 공식 문서](https://docs.openwebui.com/)와 [Alt](https://www.altalt.io/ko)의 익숙한 메뉴·작업 전환을 참고했습니다. 다른 제품의 품질·안정성 확인으로 MCastTalk의 시험을 대신하지 않습니다. [모바일로 이어갈 개선 후보](MOBILE_EVOLUTION_FROM_FIRST_RUN_REPAIR.md)는 별도 기기 검증이 필요한 설계 기록입니다.
