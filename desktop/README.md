# MCastTalk 0.2.49-desktop

Windows에서 통역 방송, 음성노트와 파일 전사를 준비하는 프로그램입니다. 왼쪽 메뉴에서 작업을 고르고 중앙 화면에서 진행합니다. 실행파일 하나를 연 뒤 모델·추론 엔진을 별도로 준비합니다.

**첫 실행 확인:** 현재 후보는 실제 Windows CPU 환경에서 저장된 파일로 구동하는 경로와, 공식 7개 파일을 새로 준비한 뒤 별도 구동 작업으로 확인하는 경로를 모두 통과했습니다. 두 경로에서 22개 기능 연결 확인과 CPU 세 엔진 준비를 확인했습니다. 사람 평가 품질·실제 마이크 지연·다른 PC 성능은 따로 확인해야 합니다. 이전 공개 [0.2.48-desktop](https://github.com/dashjeong/MCastTalk/releases/tag/v0.2.48-desktop)의 기록과 실행파일은 보존합니다. 준비와 복구 방법은 [첫 실행 안내](docs/FIRST_RUN_REPAIR_0.2.49-desktop.md)에 정리했습니다.

## 처음 실행

1. **PC 확인:** EXE를 열고 **모델·PC 진단**에서 Windows 실행 조건, 저장 공간과 여유 RAM을 확인합니다.
2. **파일 준비:** **환경 일괄 구성**에서 모델·실행 엔진의 용량과 이용조건을 확인하고 동의한 뒤 준비합니다. 실행 조건이 아직 맞지 않아도 Windows x64·저장 공간 조건이 맞으면 **파일 먼저 준비**를 선택할 수 있습니다.
3. **구동 확인:** 파일 준비 뒤 **저장된 환경 구동 확인**을 실행합니다. CPU 번역·음성인식·음성 출력과 선택 언어의 고정 시험이 모두 성공해야 **기능 연결 확인**으로 표시합니다.
4. **사용 시작:** 방송 또는 음성노트를 열고 마이크를 켭니다. 방송 시작·종료와 마이크 제어는 별도입니다. 실제 문장과 청취로 인식·번역·발음·지연을 확인합니다.

**파일 준비 완료**와 **기능 연결 확인**은 다른 상태입니다. 받은 파일만으로 모델 구동이나 통역 품질을 판정하지 않습니다. 준비가 중단되면 파일을 유지한 채 **PC 다시 확인** 또는 **저장된 파일로 이어서 준비**를 이용하세요. 구동 중에는 모델 선택을 바꿀 수 없습니다.

## 방송과 개별 대화

관리 메뉴에서 방송·음성노트·모델 준비를 고르고, 참여자는 초대 주소 또는 역할별 QR로 접속합니다. 공개 공지는 선택 언어별로 공유하며 개인 대화는 지정된 두 참여자의 채널에서 진행합니다. 교사 권한만으로 다른 참여자의 개인 채널을 볼 수 없습니다. 참여 화면에서 원음·자막·번역 음성과 저장된 음성 재생을 확인하세요. 언어별 처리가 실패하면 해당 상태를 표시하며 원음과 성공한 결과는 보관합니다.

## 준비와 사용의 확인 범위

새 CPU 기본 음성인식 모델은 약 190MB의 **Whisper Small (Q5)**입니다. 기존 Turbo/Turbo Q5는 자동 변경하지 않습니다. **CPU 시작용 음성인식 모델 선택**을 누를 때 음성인식 모델만 바꾸고 번역 모델과 CPU 설정은 유지합니다.

Microsoft 실행 구성요소 설치파일은 파일 준비 중 캐시할 수 있습니다. 이때 설치하지 않으며 실제 구동 확인에서 서명 검증과 Windows UAC 설치 절차를 진행합니다. 재부팅 필요·설치 진행 중·구동 실패는 완료가 아닙니다.

22개 기능 확인은 고정 합성 WAV의 결과와 합성 음성의 존재·연결을 확인합니다. 화면 자동 시험과 소스 검토는 실제 Windows 모델 실행을 대신하지 않습니다. 사람이 평가한 인식·번역·발음 품질, 마이크부터 청취자까지 7초 지연, 300명·장기·GPU/NPU 성능은 별도 실제 시험이 필요합니다.


## 첫 실행의 일괄 환경 구성

선택 모델과 CPU 대체 런타임은 함께 준비하며, CUDA 선택 시 추론 런타임·CUDA DLL, Vulkan/OpenVINO 선택 시 해당 런타임을 추가합니다. 파일은 고정된 출처·버전·크기·SHA-256으로 검증하고 런타임 ZIP과 음성 모델 tar.bz2는 안전한 경로에 해제합니다. 원본 아카이브뿐 아니라 공식 원본에서 산출한 전체 내부 파일 검증값과 설치 트리도 대조합니다. 설치 폴더의 검증 명세와 파일을 함께 변조한 경우도 거부합니다. 설치 상태가 바뀌면 다운로드 계획도 바뀌므로 용량·이용조건을 다시 확인해야 합니다. Windows x64 실측 진단과 여유 디스크 조건을 만족하면 파일을 먼저 준비할 수 있습니다. 실제 구동 확인에는 선택 구성의 여유 RAM과 완료된 Windows 실행 기반 진단이 추가로 필요합니다. 파일 준비 가능과 실제 실행 가능을 구분하며, 서비스·엔진·다른 설치 작업과 동시에 구성할 수 없습니다.

Windows의 Microsoft VC++ x64 DLL·버전도 점검합니다. 파일 준비 단계는 공식 고정 설치파일 약 18.7MB를 내려받고 해시를 확인해 보관하며, Windows를 설치하거나 UAC 승인을 요청하지 않습니다. 실제 구동 확인 단계에서 설치가 필요하면 Microsoft 서명을 확인한 뒤 일반 Windows 관리자 승인(UAC)으로 설치합니다. 승인 거절·설치 실패·재부팅 필요·취소 후 설치 지속 가능성은 완료로 판정하지 않습니다. 캐시 파일의 서명 신뢰 확인은 인터넷 조회 없이 수행하며, Windows의 신뢰 정보가 부족하면 설치를 중단하고 이유를 안내합니다.

구성 작업은 선택 파일을 순서대로 받고 완료한 파일을 재사용합니다. 실패·취소 시 완료 파일을 보존하고, 재부팅으로 중단되면 자동으로 완료 판정을 내리지 않습니다. 다시 실행한 뒤 일괄 구성을 선택하면 저장된 파일을 재사용하고 구동을 다시 시험합니다. 전체 파일과 엔진을 설치해도 언어별 음성 시험이 실패하면 준비 완료로 표시하지 않습니다.

구동 시험은 온라인 번역 API를 사용하지 않고 로컬 모델을 시험합니다. 소스 언어와 대상 언어마다 합성된 시험 음성을 WAV로 전사하고, 강사에서 참여자로 전달하는 번역과 참여자에서 강사로 전달하는 역방향 번역을 확인합니다. 이것은 출력이 존재하고 처리 경로가 이어지는지 확인하는 기능 시험입니다. 사람이 듣는 발음·의미 정확도, 실제 마이크 입력부터 청취까지의 7초 지연, 30·100·300명 이상의 추론 성능은 이 결과로 인증하지 않습니다. 저장된 시험 기록은 현재 설정과 파일 구성이 달라지면 이전 환경의 기록으로 표시합니다.

일괄 구성은 선택 언어에 맞는 음성 런타임과 ONNX 모델을 함께 받습니다. Supertonic 3 INT8 모델은 한국어·영어·일본어·스페인어 등 31개 언어를, Kokoro INT8 모델은 이 구현에서 중국어를 담당합니다. 5언어 조합의 추가 원본 다운로드는 약 296MB입니다. Windows 언어팩 없이 이 모델의 실제 초기화·언어별 합성을 시험하고, 미지원 언어·누락 모델·기동 실패를 명확히 안내합니다. 다른 언어로 임의 대체하지 않습니다.

모델 파일 준비와 실제 사용 가능은 구분합니다. 대상 언어의 실제 합성 시험을 모두 통과해야 음성 준비로 판정합니다. CPU·가속 방식과 번역·인식 모델 조합도 대상 PC에서 직접 구동해야 사용할 수 있습니다. GPU/NPU 드라이버는 OS 구성요소이며 모델 패키지에 복사하지 않습니다. 각 음성 모델과 eSpeak NG 데이터의 별도 이용조건은 일괄 구성에서 확인할 수 있고, 원문은 실행파일에 포함합니다.

HTTP 응답 헤더·TLS 협상 대기 제한과 2분 네트워크 수신 유휴 제한을 추가했습니다. 데이터가 계속 들어오는 정상 다운로드의 전체 소요시간에는 제한을 두지 않습니다. 일시적인 DNS·네트워크 장애와 재시도 가능한 HTTP 응답은 총 3회까지 시도하고, `Retry-After`를 제한된 대기 범위에서 반영합니다. 지원하는 서버에서는 검증한 부분 파일을 이어받습니다. 파일 크기·해시·범위 검증 실패는 재시도로 무시하지 않습니다. 정상 Windows 종료와 VM 재시작 뒤 실제 대형 모델 두 개가 재사용되는 것을 확인한 이전 시험 기록이 있습니다. 갑작스러운 전원 중단 중 자료·작업·실시간 채널의 연속성은 별도 시험이 필요합니다.

새 CPU 기본 음성인식 모델은 약 190MB의 Whisper Small (Q5)입니다. 공식 whisper.cpp 배포 저장소의 고정 파일과 SHA-256을 대조합니다. 기존 CPU의 Whisper Turbo·Turbo Q5 설정에서는 **CPU 시작용 음성인식 모델 선택**을 눌러 음성인식 모델만 바꿀 수 있고, 번역 모델과 CPU 설정은 유지합니다. 자동 전환하지 않으며 다른 가속 설정과 사용자 선택 모델은 이 전환 대상이 아닙니다. Small Q5의 자원 부담 감소는 인식 정확도·7초 지연·300명 운영의 증명이 아닙니다.

새 일괄 구성의 다운로드·검증·실패·취소·재사용·5개 언어 호출 연결은 작은 localhost 파일과 엔진 인터페이스 fixture로 자동 시험했습니다. 실제 Windows 실행파일·대형 모델·다중언어 음성·GPU/NPU의 확인 범위는 개별 시험 증빙으로 확인해야 합니다.

## 자료와 재시작

자료는 `%APPDATA%/MCastTalkDesktop`에 보관합니다. 입력 원음과 준비 중 전사 작업, 문장·번역·작업 상태를 디스크에 반영합니다. 재시작하면 진행 중 작업에 녹음 공백을 표시하고 저장된 작업을 재개합니다. 브라우저 마이크는 사용자가 다시 켜야 합니다. PC가 꺼진 동안 들어오지 않은 음성은 복구할 수 없습니다.

작업 이력에서 JSON/TXT/Markdown/SRT/ZIP을 내려받고 WAV 원음을 확인할 수 있습니다. SRT 시각은 전사 이벤트를 기준으로 하며 정확한 단어별 음성 정렬을 보장하지 않습니다. 백업에는 API 키·접속 토큰·모델 파일을 포함하지 않습니다. Windows API 키는 현재 사용자용 DPAPI로 보관합니다.

## 인터넷 없이 환경 옮기기

관리자의 **오프라인 환경 옮기기**에서 ZIP 또는 폴더로 내보냅니다. 온라인 PC에서 선택한 모델·음성·실행 엔진과 CPU 대체 런타임의 파일을 먼저 준비해 옮길 수 있습니다. 파일 준비만 마친 환경과 원본 PC에서 실제 구동을 확인한 환경을 구분하며, 대상 PC의 구동·음성·품질은 따로 확인합니다. 기본 내보내기는 선택 모델과 CPU 대체 런타임이 없으면 누락 항목을 안내합니다. 고정 Microsoft VC++ 설치 캐시도 포함하며, 캐시가 없으면 오프라인 구성 불완전으로 안내합니다. 가져오기는 설치파일을 보관하고, 이후 일괄 구성에서 별도 동의·서명 검증·정상 UAC 설치를 진행합니다. 실행파일과 전역 용어집·대본·승인 자료는 선택해서 포함할 수 있습니다. 인증키·PIN·TLS 개인키·개인 대화·녹음·참여자는 포함하지 않습니다.

패키지를 USB 등으로 대상 Windows x64 PC에 옮기고 **패키지 검사 → 검사한 환경 가져오기**를 실행합니다. 파일 목록·크기·SHA-256, 고정 모델 프로필, 동일 앱 버전·OS·아키텍처, 여유 디스크를 검사합니다. 검사 후 같은 경로의 패키지가 바뀌면 다시 검사해야 합니다. 가져오기는 HF·온라인 API·CDN 요청이나 모델 다운로드, 가져온 실행파일의 자동 실행을 하지 않습니다. 큰 모델은 메모리에 모두 넣지 않고 스트리밍 복사하며 ZIP Store를 사용합니다.

가져오기 전 엔진·세션·강의실·입력·대기 작업·기기 접속을 종료하세요. 검증한 파일은 새 관리 경로에 저장하고, 설정·설치 목록·선택 자료를 한 Bolt 트랜잭션으로 적용합니다. 기존 모델과 자료는 보존합니다. 실패·취소는 기존 환경을 유지합니다. 재부팅으로 중단된 이전 작업은 완료로 표시하지 않으며, 중단 직후 설치 상태를 확인하고 재검사하세요. 갑작스러운 전원 중단으로 남은 미적용 임시 파일의 자동 정리는 아직 제공하지 않습니다.

적용 후 CPU·오프라인·로컬 접속 설정으로 다시 실행하고 **PC 진단 → 엔진 시작 → 실제 통번역 성능 시험**을 진행합니다. 원본 PC의 성능 판정은 대상에 승계하지 않습니다. 선택 언어의 ONNX 음성 모델과 런타임은 패키지에 포함합니다. GPU/NPU 드라이버 등 OS 구성요소는 복사하지 않습니다. 대상 드라이버를 준비하고, 가져온 음성 모델과 번역·인식 엔진이 오프라인에서 작동하는지 직접 확인하세요. 로컬 네트워크·휴대폰 신뢰 설정·HTTPS 인증서는 대상에서 별도로 구성합니다. 인터넷이 없어도 로컬 LAN은 필요합니다.

무결성 해시는 패키지 배포자의 신원을 인증하지 않습니다. 신뢰하는 PC에서 만든 환경만 가져오세요. 자동 시험과 브라우저의 ZIP/폴더 이전은 작은 시험 파일로 확인했으며, 실제 Windows 모델 실행과 인터넷을 차단한 OS 수준의 운영 검증은 별도입니다. 상세 요구와 한계는 [오프라인 이전 계약](offline-portability.json)을 확인하세요.

## 네트워크

관리 화면은 `127.0.0.1:8790`, 청취 서버는 `127.0.0.1:8787`입니다. 설정에서 LAN IP 또는 `0.0.0.0`과 포트, 휴대폰에서 접근할 HTTPS 주소·인증서·개인키 경로를 선택하고 다시 실행하면 LAN 참여를 제공합니다. loopback 외의 대화방 인증 API·WebSocket과 원격 웹 마이크에는 HTTPS가 필요합니다. 강사·학생 초대 QR은 역할이 구분되며 개인 채널에는 지정된 두 사람만 접근할 수 있습니다. 교사 권한만으로 다른 사람들의 개인 채널을 조회할 수 없습니다.

DDNS 외부 서비스는 HTTPS 주소와 그 이름에 맞는 PEM 인증서·개인키를 설정합니다. 인증서 발급/갱신과 DDNS 갱신, 공유기 포트 전달은 운영 환경에서 구성해야 합니다. 관리 포트는 외부에 공개하지 마세요. 기본 정원 512명은 설정값이며 검증된 모델 동시 수용량이 아닙니다. 실제 네트워크·언어 수·모델·장치로 부하 시험을 실행하세요.

## 단계별 시험 목표

최종 목표는 300명 이상 대형 강의입니다. 첫 실제 POC는 **30명 이상·5개 언어 이상**으로 시작하고, 품질·사용자 체감 지연·자료 복구를 확인한 뒤 100명, 300명 이상으로 확대합니다. 동시 접속자, 서로 다른 대상 언어, 동시 발화자 수는 별도 측정합니다. 300명 접속을 300명 동시 발화 처리 능력으로 표시하지 않습니다.

같은 발화와 대상 언어의 번역·음성은 한 번 생성해 해당 언어의 참여자에게 공유하는 구조를 목표로 합니다. 실제 모델 처리 부하와 이미 생성한 결과의 전송 부하를 각각 시험합니다. UI 시연과 가상 사용자 시험의 통과는 실제 음성·모델·Windows·동시 접속 성능의 통과를 의미하지 않습니다.

## 빌드

Go 1.25 이상과 모바일 웹 리소스 동기화용 Python 3이 필요합니다. 최종 EXE에는 Go·Python 설치가 필요하지 않습니다.

Windows 10 버전 1903(build 18362) 이상 또는 Windows 11을 대상으로 합니다. 프로세스 UTF-8 설정을 실행파일에 포함해 한국어·중국어·일본어 자료 경로의 네이티브 음성 모델 파일 접근을 지원합니다. 이 설정은 시스템 언어나 시스템 로캘을 변경하지 않습니다. 지원 Windows 버전은 [Microsoft 프로세스 UTF-8 문서](https://learn.microsoft.com/en-us/windows/apps/design/globalizing/use-utf8-code-page)에 근거합니다. Windows 11 평가 VM의 해당 경로에서 5언어 합성 10회를 확인했으며, 모든 경로·구버전 Windows 호환성을 인증한 것은 아닙니다.

`windows-app.manifest`와 아키텍처별 `.syso` 리소스를 함께 관리합니다. 빌드는 실제 EXE의 PE 리소스에서 매니페스트·UTF-8·일반 사용자 권한을 검사하고, 소스와 다르면 실패합니다. 매니페스트를 수정할 때는 `github.com/akavel/rsrc@v0.10.2`로 `rsrc -arch amd64 -manifest windows-app.manifest -o resource_windows_amd64.syso`와 ARM64 대응 명령을 실행해 두 리소스를 재생성하세요.

```powershell
./scripts/build-windows.ps1
./scripts/test-windows.ps1 -Iterations 5
```

개발용 실행은 `go run . -no-browser -admin-token-file ./local-admin-token`입니다. 토큰 파일은 개인 로컬 시험용입니다. 제품/백업/공유에 넣지 마세요.

Windows ARM64 실행파일을 만들 수 있지만, 기본 추론 런타임은 Windows x64 기준입니다. ARM64 모델 추론은 해당 장치용 런타임을 별도로 확인해야 합니다. CUDA·Vulkan·OpenVINO/NPU 및 음성 품질·지연은 실제 장치 시험이 필요합니다.

MCastTalk 소스의 Apache-2.0과 포함 라이브러리의 별도 고지를 준수하세요. 모델·추론 엔진은 각각의 이용조건을 따릅니다.
