로컬 통역과 강의실을 관리합니다. 개인대화는 지정된 두 당사자에게만 전달합니다.

      강의실 · 개인대화

      30명 이상·5개 언어 이상으로 시험을 시작하고 100명 → 300명 이상으로 확장합니다. 등록 정원은 설정값이며 실제 통역 처리 성능을 보증하지 않습니다. 강사·학생은 서로 다른 초대 주소에서 참여하며, 개인대화는 지정된 당사자에게만 전달됩니다.

      모델 · PC 진단

      Hugging Face 모델 추가

      저장소의 선택 리비전을 고정된 커밋과 SHA-256으로 등록합니다. 새 모델은 실제 구동과 품질 시험 전까지 실험 후보입니다.

      선택 가능한 모델

      오프라인 환경 옮기기

      온라인 PC에서 모델·실행 엔진을 준비하고 실제 구동을 확인한 뒤 내보내세요. USB 등으로 옮긴 ZIP 또는 폴더를 인터넷 없이 가져올 수 있습니다.

      인증키·PIN·TLS 개인키·개인 대화·녹음·참여자 정보는 포함하지 않습니다. 대상 PC의 관리자 인증을 사용하며 모바일 접속용 로컬 네트워크·HTTPS는 대상에서 설정하세요.

      환경 내보내기

      선택 모델·CPU 대체 엔진·설치한 가속 엔진을 확인합니다. 기존 목적지를 덮어쓰지 않습니다.

      환경 검사·가져오기

      검사는 파일·버전·플랫폼·공간을 확인합니다. 가져오기 전 엔진·강의실·대기 작업·접속을 종료하세요.

      가져오면 CPU·오프라인·로컬 접속으로 적용됩니다. 프로그램을 다시 실행하고 엔진·음성·통번역 성능을 확인하세요.
