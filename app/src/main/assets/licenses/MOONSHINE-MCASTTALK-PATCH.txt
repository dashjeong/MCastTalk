Local changes (not an official upstream release):
- Correct the maximum-segment confidence fade, including a finite bound when
  VAD is disabled for diagnostic use. Keep normal VAD enabled.
- Make Silero tensor/inference/output errors observable, with scoped ORT
  cleanup instead of treating a failed inference as a zero speech probability.
- Release JNI input float arrays in both streaming and batch transcription;
  release model-load UTF strings, and own debug round-trip transcript copies.
- Propagate native transcription, audio-input, stream-start and stream-stop
  errors as Java IllegalStateException with operation and numeric error code.
  Keep freeStream cleanup behavior unchanged to avoid masking an existing
  exception. Do not add transcript/audio content logs.
- Reject missing native stream handles before dereferencing them. Repeated
  cleanup of a missing stream is a no-op, without inserting a null stream.
- Clear prior session confidence and look-behind PCM windows when starting
  a VAD session. Include a restart regression; shared Silero recurrent-model
  state is unchanged by this bounded patch.
- Add native regression checks for fade continuity and bounded VAD-disabled
  segments. The native segment bound is a decoder resource limit, not a
  semantic sentence boundary.
