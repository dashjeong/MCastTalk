Piper Arabic Kareem Medium voice and Arabic G2P assets
------------------------------------------------------
GuideCast asset id: piper_ar_JO-kareem-medium
Pinned by: Moonshine Voice 0.1.5 native streaming manifest
Output locale/sample rate: ar_JO / 22,050 Hz
piper-voices repository metadata: MIT
The Kareem model card delegates its dataset license to
https://github.com/AliMokhammad/arabicttstrain/ . That source repository does not
publish a detected license. The required Arabic diacritizer checkpoint
AbderrahmanSkiredj1/arabertv02_tashkeel_fadel also has no license metadata.
Moonshine's ar_msa README attributes dict.tsv generation to CAMeL Tools and its
MSA data. CAMeL Tools code is MIT, but that does not by itself license every
downloaded data package or the generated dictionary. Commercial redistribution
of this Arabic voice/G2P bundle therefore requires a separate rights review.
Pinned voice/model card source:
https://huggingface.co/rhasspy/piper-voices/tree/39ab474be869e9181350af6a65e4953eef67aaa0/ar/ar_JO/kareem/medium
Moonshine 0.1.5 Arabic provenance:
https://github.com/moonshine-ai/moonshine/blob/v0.1.5/core/moonshine-tts/data/ar_msa/README.md
Arabic diacritizer source:
https://huggingface.co/AbderrahmanSkiredj1/arabertv02_tashkeel_fadel
