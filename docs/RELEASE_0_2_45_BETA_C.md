# 0.2.45-beta-c — 음성노트 전사 대기열 보완

음성노트에서 인식기가 입력을 잠시 따라가지 못하면 크기 32의 PCM 대기열이 가득 차면서 전사 작업을 취소하던 경로를 변경했다. 녹음 WAV에 저장된 데이터를 단일 커서로 읽어 인식기에 순서대로 전달하며, 녹음 작업을 인식기의 처리 속도와 분리한다. 메모리를 무제한으로 늘리거나 PCM을 버리는 방식은 사용하지 않는다.

디스크 읽기 오류와 파일 잘림은 오류로 전달한다. 녹음 종료 시 마지막 확정 바이트를 다시 확인하며, 지연된 전사 문장의 시간은 인식기에 전달한 음성 위치를 기준으로 계산한다. 기존 녹음 길이 제한과 종료 후 최대 8초의 잔여 전사 대기 정책은 유지한다. 그 시간 내 처리하지 못한 음성은 WAV에 보관되지만 전사 완료를 보장하지 않는다.

## 검증 범위

- 새 JVM 회귀시험 12건 통과: 대기열 포화 동작, 저장된 PCM의 순서·내용·시간, 단일 소비자, 취소·닫기, 잘림·하위 처리 오류, 입력 검증, 종료 시 마지막 데이터와 지연 전달 시간.
- 앱 Alpha 단위시험 결과 546건, translation 255건, stream 28건에서 실패·오류·skip 0건 확인. 변경되지 않은 Gradle 작업은 기존 결과를 재사용할 수 있다.
- Alpha lint 오류 0건 및 공개 소스 경계 검사 통과.
- 정확한 공개 서명 APK의 설치·기능 시험 결과는 [시험 보고서](TEST_REPORT.md)에 별도로 기록한다. JVM 통과가 마이크 입력·청취 출력 성공을 대신하지 않는다.
