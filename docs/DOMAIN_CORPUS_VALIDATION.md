# 도메인 코퍼스 검증 기록

이 문서는 0.2.46-beta-d 후보의 도메인 코퍼스 변경과 실제 시험 증거를 연결한다.
최종 배포 승인이나 휴먼 통역 99% 달성 보고서가 아니다.

## 요구사항과 구현

- 사용자 TXT의 원문·번역을 탭으로 구분해 가져오기/내보내기한다.
- 언어쌍과 문체별 프로필을 활성화한다. 확인된 전체 문장의 정확한 일치는 직접 적용하고,
  새로운 문장은 관련 예문과 도메인 설명을 로컬 Gemma의 참고 입력으로 사용한다.
- 모델 가중치 훈련이나 강화학습을 실행했다고 표현하지 않는다. 현재 구현은 사용자가
  검토한 병렬 문장과 검색 기반 참고를 즉시 적용하는 방식이다.
- 도메인 기능을 끄면 기존 번역 프롬프트·원음·PCM 경로를 보존한다. 별도로 요청된
  마지막 문장 무한 대기 수정은 `IDLE_SENTENCE_RECOVERY.md`에 구분해 기록한다.
- 코퍼스 읽기 오류는 기존 번역으로 복구하고 개인정보를 진단 로그에 기록하지 않는다.

## 문제 → 수정 → 재시험

| 발견한 문제 | 수정 대상 | 확인 방법 |
|---|---|---|
| 활성 전환 뒤 이전 캐시가 다시 게시될 수 있음 | 캐시 읽기·게시와 활성 변경의 동일 잠금 | 전환 및 경쟁 회귀시험 |
| 새 래퍼가 기존 번역 watchdog 예산을 잃음 | BoundedQueuedTranslationEngine 계약 보존 | 느린 번역 회귀 및 예산 검사 |
| 비활성 상태에서도 프롬프트에 빈 줄이 추가됨 | 기존 본문 보존, 활성 상태에서만 참고 블록 추가 | 이전 버전 고정 프롬프트 검사 |
| 음성 입력 ko-KR과 가져온 ko가 불일치 | 지원 언어 별칭 정규화 | 실제 입력 태그를 사용하는 코퍼스 시험 |
| 파일 읽기/내보내기 실패가 성공으로 보일 수 있음 | 실패 안내·재시도, null 스트림 실패 처리 | 사용자 파일 선택 흐름 |
| 큰 글자에서 고정 안내가 화면을 차지함 | 내용 전체 스크롤과 최소 기능 우선 배치 | 좁은 화면·큰 글자 검증 |

실행 결과와 추가 수정은 시험 종료 후 아래 증거에 연결한다. 위 표 자체는 시험 통과 증거가 아니다.

## 자료와 누출 방지

회의·업무 자료는 36개 합성 훈련쌍과 별개의 12개 한국어 시험문장이다.
영어·일본어·중국어 간체 참고 번역은 Antigravity의 Gemini가 모델 출력 이전에 작성했다.
인용된 오기를 그대로 보존해야 하는 MC05는 모델 실행 전에 원문에 근거해 별도 참조로 고정했다.
이는 AI 참조 번역이며 인간이 검수한 정답이라고 표시하지 않는다.

공식 발언 자료는 [북한정보포털 주변국 발언](https://nkinfo.unikorea.go.kr/nkp/report/list.do?pstgSeCode=ARGUMENT_MJOR&menuId=MENU_604)의
원문·한국어 대응 필드에서 추출한다. 사용자가 해당 자료의 인간 번역 출처를 확인했다.
문서 단위로 훈련·개발검증·최종시험을 나누며 반복 원문은 같은 분할에 둔다.
한국어→외국어 평가는 공식 자료의 외국어→한국어 번역 방향을 역으로 사용한 평가다.
문단 대응·숫자·추가 설명을 대조한 쌍만 실제 학습 입력으로 사용한다.

수집 범위는 60개 문서, 원문과 번역이 있는 111개 발언 항목이다.
영어·중국어·러시아어 자료를 확인했으며, 이 수집 범위에서는 일본어 원문을 찾지 못했다.
일본어 시험은 별도의 합성 회의 자료로 수행한다.

[공식 저작권 정책](https://nkinfo.unikorea.go.kr/nkp/pge/view.do?menuId=COPYRIGHTPOLICY)에 따라
공식 원문 코퍼스는 로컬 연구·평가 자료로 보관한다. APK나 공개 Git 저장소에 포함하지 않는다.
상업용 재배포 권한을 확보했다고 주장하지 않는다.

## 시험 판정

같은 APK·같은 모델·같은 미학습 문장에서 도메인 OFF/ON을 비교한다.
시험문장이 정확 일치 사전으로 반환되면 미학습 품질 시험에서 실패 처리한다.
번역 완료와 비어 있지 않은 출력은 기능 판정이며 의미 정확성 판정과 분리한다.

의미 판정은 숫자·단위·부정·행위자·사역·시간·인용·문체를 원문과 대조한다.
참고 번역과 단어가 다르다는 이유만으로 오역으로 분류하지 않는다.
실행 전 고정한 개발검증 자료로 개선하고 최종시험 자료를 학습 입력으로 사용하지 않는다.

지연은 모델 준비 시간, 코퍼스 검색 시간, 텍스트 번역 시간을 구분한다.
텍스트 번역 시간만으로 첫 음성 p95 2,000ms 게이트를 통과했다고 보고하지 않는다.
기존 물리 S23+ 시험에서 확인된 E2B 안전 표지판 의미 오류는 별도의 회귀 대상으로 유지한다.

## 실제 비교와 개선 결과 (2026-10-02)

회의 자료의 최초 실제 E4B 추론은 S23+에서 12개 미학습 문장 × 영어/일본어/중국어 간체 ×
OFF/ON = 72개 출력이 모두 완료했다(241.553초). 이는 의미 검수를 통과한 72건이라는 뜻이 아니다.
코덱스 판정은 OFF 26 PASS/5 MINOR/5 MAJOR, ON 27/4/5였다.
안티그래비티 독립 판정은 OFF 29/5/2, ON 31/3/2로, 명시 오기 인용의 심각도 판단에
차이가 있었다. 평균으로 합쳐 정확도를 높여 보고하지 않는다.

발견한 핵심 오류는 원화의 일본 엔화 치환, 원문 그대로 인용해야 하는 오기의 임의 번역,
지시받는 사람과 지시자가 직접 수행하겠다는 약속의 혼동이었다. 단일 통화·동일 숫자·유일
인용이라는 조건을 만족할 때만 보정하고, 일반 인용·환전·다중 통화·모호한 역할은 추측으로
치환하지 않는 가드를 추가했다. 역할 보존 참고 지시도 도메인 활성 프롬프트에만 추가했다.

새 DEV는 실행 전에 고정한 별도 6개 사례 × 3개 언어 × OFF/ON = 36개 출력이다.
코퍼스 SHA-256은 `96d521c8de96a04e231e846957d9f6ad99fb13dad945945ddd5e309f838a0265`.
수정된 E4B 실제 S23 추론은 137.386초에 36건을 완료했다. 안티그래비티 독립 AI 검수는
OFF 12 PASS/4 MINOR/2 MAJOR, ON 14/4/0이다. ON에서 명시 오기 인용은 한국어 원문을
보존했고 일반 대화 인용은 번역했다. 직급 대리의 代理人 표기, 문맥의 ‘두 비용’ 누출,
‘작년보다’에 ‘동기’를 더하는 경미한 문제는 남았다. 이 DEV 개선으로 최초 72건 전체의
해결이나 인간 통역 품질 인증을 선언하지 않는다.

공식 자료는 최초 수집/가공본의 30쌍에서 수정된 문구·숫자·대응 오류를 발견해 제외했다.
검토 v2는 실제 원문 필드의 연속 구간 82쌍(TRAIN 54/DEV 14/TEST 14)을 동결했다.
문서 단위 분할과 원문 SHA/오프셋을 유지하고 동일 정규화 원문·번역의 분할 간 중복은 0이다.
가공된 과거 자료는 격리해 학습 입력에 쓰지 않는다. 해시·구간 검증은 인간 의미 검수를
대신하지 않으며, 추가 주어·시간·공동 개최 여부가 다른 3개 공식 참조는 비대칭으로 표시한다.

공식 DEV 14개 × OFF/ON 28개 실제 S23 출력은 159.881초에 완료했다.
코덱스 판정 OFF 11/1/2, ON 13/1/0; 안티그래비티 OFF 10/3/1, ON 14/0/0이다.
회사·소비자를 합의 당사자로 더하던 병렬 구조와 당 대 당 교류 누락이 ON에서 개선됐다.
최종 TEST는 DEV와 다른 문서이며 학습 예문으로 넣지 않는다. 최종 TEST 실행·의미 판정이
완료되기 전에는 최종 정확도를 보고하지 않는다.

실제 SQLite 10,000쌍 조회는 S23에서 최초 67.221511ms, 준비 후 30회 p95 5.550937ms였다.
그러나 E4B+설치된 Android 오프라인 영어 TTS의 별도 20표본 native 첫 PCM p95는
2,041ms로 2초 목표를 초과했다. 도메인 정확 일치·검색 성능과 실제 번역/음성 지연을
혼동하지 않는다. 상세 환경과 최종 APK 해시는 TEST_REPORT에 연결한다.

최신 navigation 후보에서 최초 고정 72개 출력을 다시 실제 추론했다. ADB 연결이 바뀌어
host runner 종료 토큰을 받지 못했으나 기기의 JSON 72개 출력과 functionalCompletion,
cleanupCompleted를 회수했다. JUnit 통과로 표시하지 않는다. 원래 MC01 원화 및 MC05
오기 인용은 ON에서 보존됐다. 일본어 MC09의 부정절에 과장 본인의 행위 주체가 여전히
잘못 전달되어 해결 완료로 판정하지 않는다. 코덱스 독립 AI 전수 검수는 OFF 26 PASS /
5 MINOR / 5 MAJOR, ON 31 / 4 / 1이다. 최초 ON 대비 5개 판정이 개선됐으나 영어 MC11의
직급 정밀도는 MINOR로 후퇴했고 30개는 동일했다. 안티그래비티의 같은 72개 독립 검수는
OFF 26/5/5, ON 32/3/1이다. 7개 행의 판정에 차이가 있으며, 일본어 MC09의 ON 중대 오류는
두 검수 모두 확인했다. 판정은 각각 제시하며 평균으로 합치지 않는다. 고정 합성 자료의 AI
판정을 일반 오류율이나 인간 수준 정확도로 확대하지 않는다.

동일 APK의 Android 오프라인 TTS 20회 재측정도 첫 native PCM p95 2,049ms로 실패했다.
코드 최적화 전후 비교가 아닌 동일 기준선의 반복이다. 이후 동결된 공식 최종 TEST를 실제
시도했으나 135.824초에 10,000ms 번역 제한 예외로 실패했다. 21개 출력만 완료했고 다음
중국어 ON 항목 NK-10719-0-TEST-POLICY-V2는 RUNNING 상태로 남았다. 정리는 완료됐다.
해당 원문은 118자, 참고 힌트는 1,134자이지만 힌트 길이가 원인이라는 결론은 아직 입증되지
않았다. 최종 TEST의 전체 기능·의미 검수 통과가 아니며, 현재 후보를 공개 배포 합격본으로
전환하지 않는다. 원문 코퍼스와 상세 출력은 계속 로컬 연구 자료로만 보관한다.

## 2026-10-03 추가 후보와 실제 검증 한계

E4B 일반 번역 경로에도 좁은 원화·명시 오기 인용 가드를 적용하고, 행위자와 자기 수행
약속을 구분하는 일반 프롬프트를 보완했다. 이전 ON 전용 수정과 구분하며 E2B의 기존
프롬프트는 유지한다. E4B 선택 시 참고정보 예산은 600자로 제한하되, 완전한 원문·번역
예문쌍을 먼저 넣고 설명은 남는 예산에만 넣는다. 현재 번역 대상·사용자 코퍼스·정확 일치
번역은 자르거나 덮어쓰지 않는다. 600자는 토큰 상한이나 시간 초과 해결 보증이 아니다.

안티그래비티가 작성한 새로운 합성 반례 8개는 역할·부정·다중 통화·인용·시간·조건을
포함하며 실행 전 문체 및 행위자 가정을 교정해 v1.0.1로 동결했다. AI 참고 번역이며
인간 정답 인증이 아니다. 원본 SHA-256:
`e85d3d4519bf93e12131b5c416c712e7abef20432db2a52a2edb21fc1d01f0fc`.
Android runner 배열 SHA-256:
`b351d7c1e93eb76d43b15b43e206fbebe0986f54aef688fe166c32a98f2034c2`.
기존 회의 TRAIN과 정확 일치하는 시험 원문은 없다. 참고 정답을 모델 지시에 넣지 않는다.

최신 recovery APK의 실제 에뮬레이터 도메인 저장소 회귀는 5건 통과했다. 그러나 E4B
CPU 실제 추론은 첫 RC01 영어 OFF 항목에서 기존 10초 제한으로 실패했다. 결과에는
TIMED_OUT과 cleanupCompleted가 기록됐으며 완료 번역은 0건이다. 따라서 계획된
48개 OFF/ON 번역과 새 의미 비교가 끝났다고 표현하지 않는다. 새 APK에서 기존 MC09
역할 오류나 공식 자료의 시간 초과가 해결됐는지도 아직 입증되지 않았다. S23+ 연결
복구 전까지 이전 APK의 지연 성공을 새 품질 수정본의 성공 근거로 사용하지 않는다.
정확한 APK 해시, 실행 시간과 실패 증거는 TEST_REPORT의 추가 후보 절에 연결한다.
