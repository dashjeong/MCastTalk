## 화면 구조와 가상 사용자 검증

운영은 입력과 콘텐츠, 시험은 실제 결과 비교, 설정은 언어·모델·이관으로 유지한다.
설정의 아스트라 미니미는 필요한 화면으로 연결한다. 실험실의 자가개선 모드를 켜면
사용자가 원문을 전부 고르지 않아도 후보를 선별하고 개선안을 제시한다.
코드 변경이 필요한 제안은 개발 검토 승인으로 기록하며 앱을 스스로 다시 빌드하거나
설치하지 않는다. 안전한 설정 조정과 문장 보정만 사용자의 승인 후 실행한다.

- 현장 진행자: 입력이 멈춤 → 비서의 관측 확인 → 입력 복구 화면 → 방송 유지 여부 확인.
- 품질 담당자: 모드 활성화 → 자동 선별 → 전후 리포트 → 보류/승인 → 동일 문장의 적용 확인.
- 데이터 관리자: 승인 전·후 기록과 사전 백업 → 새 설치에 가져오기 → 키·전송 동의 미복원 확인.
- 큰 글씨 사용자: 360dp 폭에서 카드·승인/보류·돌아가기 스크롤 접근 확인.

## 품질과 성능의 측정 기준

지연은 준비 상태·기기·언어 수·경로별로 나누어 비교해야 한다. 비서는 현재 남아 있는
최대 100문장의 첫 음성 지연을 언어 혼합 표본으로 계산하고 표본 수를 표시한다.
이 수치를 Galaxy S23 단일 언어 2,000ms p95 게이트나 8시간 안정성 인증으로 대체하지 않는다.
스승의 개선 분류, 숫자·언어 문자 검사, 사용자의 의미 확인은 서로 다른 근거다.
리포트는 측정하지 않은 정확도 향상률을 만들지 않는다.

모델 가중치 학습·강화학습 훈련 루프는 포함하지 않는다. ‘자기진단적 강화학습’이라는
실험실 기능은 선별된 문장의 진단·비교·승인된 보정 지식 축적을 뜻한다.
반복 빈도만으로 정상 문장을 외부에 전송하지 않으며, 새 문장 전체로 검증 없이 일반화하지 않는다.

## 배포 전 보안 확인

[OWASP 프롬프트 주입 방어 지침](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html)을
참고해 모델 입력과 실행 권한을 분리한다. 외부 결과는 텍스트와 고정된 개선 분류만 받을 수 있다.
URL·명령·코드·인증 규칙·공급자 설정을 모델 응답으로 실행하지 않는다.

필수 공격 검증은 목적지/헤더 변조, 리다이렉트, 초과·중첩 응답, 취소와 동의 철회 경합,
학습 오염·확정 문장 덮어쓰기, 승인/취소 재실행, 백업 변조·과대 입력, 서버 인증·Host·웹 출력
경계를 포함한다. 특정 상용 AI 공격 에이전트로 실제 침투시험을 했다고 주장하지 않는다.
발견한 결함의 수정·회귀와 정확한 패키지 시험을 끝낸 뒤 배포 결과를 기록한다.
