# 음성·문체 엔진 검토와 현재 적용 범위

확인일: 2026-09-14. 공식 API·릴리스와 현재 소스를 비교한 기록이다. 특정 엔진이 모든 언어·기기에서
최고라는 순위를 매기거나, 실물 Galaxy의 정확도·자연스러움·첫 음성 지연을 측정한 보고서가 아니다.
실행한 시험과 배포 APK 검증 결과는 `TEST_REPORT.md`에 별도로 기록한다.

## 현재 앱에 적용한 개선

| 경로 | 적용한 내용 | 사용 조건과 한계 |
| --- | --- | --- |
| 파일 음성 인식 | Android 온디바이스 인식에 bounded PCM 스트림과 파일 시각을 전달한다. Android 14 이상에서 언어 감지·전환 및 단어 시작 시각을 요청한다. | 외부 PCM 입력은 Android 13 이상이다. Android 13은 원문 언어를 직접 선택해야 한다. 설치된 엔진·언어팩이 요청을 지원해야 한다. |
| 파일 스크립트 | 엔진이 돌려준 단어 시작 시각을 파일 시각으로 변환한다. 대소문자가 다른 표기에도 실제 해당 단어를 강조한다. | 단어 종료 시각은 API가 제공하지 않는다. 다음 단어 시작 시각을 활용하는 표시 구간은 추정이며, 누락된 단어 시각을 만들어내지 않는다. |
| 인식 힌트 | 사용자가 확정한 짧은 문장과 기존 발음 교정 힌트를 온디바이스 인식에 전달한다. | 전체 문장 사전을 보내지 않는다. 현재 스냅샷은 최대 32개이며 공급자에서 길이도 제한한다. 인식 힌트는 정답 강제나 모델 재학습이 아니다. |
| 문체·의역 | 개발자 정보와 문체 실험을 켰을 때 문장별 문체를 Gemma 프롬프트에 전달한다. 이전 문맥·용어집·현재 번역 대상을 분리해서 유지한다. | 선택한 경로에 준비된 Gemma가 있어야 한다. ML Kit 단독 번역은 의역 설정에 따라 문체를 바꾸지 않는다. |
| 음성 표현 | 개발자 정보와 표현 실험을 켜면 Android TTS의 속도·음정을 0.9–1.1 범위로 조절한다. 문장마다 설정하고 다음 일반 문장은 기본값으로 복귀한다. | 문장 부호와 선택 문체에 따른 작은 변화다. 원음의 감정·화자 음색 복제 기능이 아니며 현재 Moonshine 음성에는 적용하지 않는다. |
| 문장 보정 | 사용자 확정 문장은 오프라인에서 재사용한다. 별도로 허용한 온라인 문장 검토는 의미 보존 검사 후 기기 사전에 저장할 수 있다. | 실시간 온라인 검토는 자동 학습도 켠 경우에만 수행하며 현재 자막·낭독을 교체하지 않는다. 이후 같은 원문·언어·문체에 적용한다. 파일 번역은 제한 시간 내 검토 결과를 반영한다. |

Android의 언어 감지·전환·단어 시각 요청은 엔진이 지원 여부를 달리할 수 있다. 앱은 실제 콜백을
검사하며 자동 감지가 확인되지 않으면 언어를 직접 선택하도록 안내한다. `RecognitionPart`의 시각은
세션 기준 단어 시작이며 종료 시각은 아니다. [RecognizerIntent 공식 계약](https://developer.android.com/reference/android/speech/RecognizerIntent),
[RecognitionPart 공식 계약](https://developer.android.com/reference/android/speech/RecognitionPart#getTimestampMillis()).

Android TTS의 음정과 속도 설정 성공은 청감 품질의 증명이 아니다. 설정 성공 여부를 확인하고
PCM 형식·순서 및 기존 합성 시작/정지 제한을 유지한다. 기본 음성/표현 음성을 같은 문장으로 비교할
수 있지만 자연스러움과 원음 감정 일치 여부는 직접 들어서 평가해야 한다.
[TextToSpeech 공식 API](https://developer.android.com/reference/android/speech/tts/TextToSpeech#setPitch(float)).

## 검토했지만 이번에 추가하지 않은 후보

**ML Kit GenAI Speech Recognition 1.0.0-alpha1**은 마이크와 파일 디스크립터의 스트리밍 인식을
지원한다. Basic은 Android API 31 이상, Advanced는 공식 지원 목록상 Pixel 10·11이다. 한국어는
Basic에서 beta로 표기된다. SDK의 최소 API 26 선언과 실제 모드 지원 조건은 구분해야 한다.
사용 가능 상태·모델 다운로드를 확인해야 하며 외부 PCM은 16 kHz mono 16-bit를 실시간 속도로
공급해야 한다. 현재 앱에는 이 의존성을 추가하지 않았다. API가 alpha이고 대상 Galaxy에서 Advanced
지원이나 정확도·지연 이득을 검증하지 못했으므로 기존 플랫폼 인식기를 자동 교체할 근거가 없다.
다음 도입 판단은 같은 음원으로 WER/CER, 언어 전환 오류, 첫 결과 지연, 장시간 자원 사용을 비교한 뒤
내린다. [Google 공식 문서](https://developers.google.com/ml-kit/genai/speech-recognition/android).

**Moonshine**은 현재 버전 카탈로그와 공식 최신 릴리스가 v0.1.5이다. 새로운 스트리밍 아키텍처의
소개만으로 앱의 한국어 legacy TINY 모델을 대체하지 않았다. 현재 고정 모델의 한국어 지원·라이선스·
해시·네이티브 메모리 사용과 종료/재시작 동작을 새 모델에서도 확인해야 한다. STT 엔진의 업데이트를
TTS의 감정 표현 개선으로 설명하지 않으며, 현재 SDK 경로에 없는 음정·감정 파라미터를 지원한다고
표시하지 않는다. [고정 릴리스](https://github.com/moonshine-ai/moonshine/releases/tag/v0.1.5),
[해당 태그의 프로젝트 설명](https://github.com/moonshine-ai/moonshine/blob/v0.1.5/README.md).

## 동의·지연·재배포 기준

개발자 실험은 기본 꺼짐이다. 온라인 검토는 개발자 표시, 온라인 전송 동의, 저장된 API 키가 모두
있어야 하며 실제 전송 직전에도 다시 확인한다. 원문·번역문·언어 정보만 선택한 공식 API에 보낸다.
음원·진단 로그·파일 경로는 보내지 않는다. 자동 학습은 모델 가중치 변경이 아니라 기기 문장 사전의
추가이며, 사용자 확정 문장을 AI 결과로 덮어쓰지 않는다. API 응답의 보수적 길이·숫자·이름 검사는
완전한 의미 검증이 아니다. 기기 성능·서비스 응답·청감 품질의 측정값은 추정값으로 대체하지 않는다.

새 운영 의존성이나 대형 모델 업그레이드는 이번 실험에 추가하지 않았다. 향후 도입 시 실제 배포
variant의 해석 버전, 공식 source/tag 또는 commit, SPDX 또는 해당 모델의 별도 라이선스,
원문 LICENSE/NOTICE, 다운로드 크기·고정 해시, 오프라인 동작과 제거·취소 경로를 확인해야 한다.
SDK 라이선스와 모델·음성의 재배포 조건은 별개다. 현재 포함 내역과 약관 출처는
`THIRD_PARTY_LICENSES.md` 및 앱의 오프라인 라이선스 화면을 기준으로 한다.

현재 검증용 소스에는 파일 디코더 fixture·청크 연속성, 문체 컨텍스트와 공정 번역 큐의 전달,
문장별 TTS 기본값 복귀, 사용자 확정 보정 우선, 온라인 응답 지연 중 초안 보존과 취소 전파에 관한
시험이 있다. 이 시험은 실제 모델 정확도, 물리 Galaxy 음성 자연스러움 또는 8시간 현장 안정성의
입증으로 사용하지 않는다.
