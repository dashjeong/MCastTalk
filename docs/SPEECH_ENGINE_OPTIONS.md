# 음성·번역 방식 선택

| 사용 방식 | 준비와 확인 |
| --- | --- |
| 기기 내 통번역 | 사용할 인식·번역 모델과 언어별 음성을 다운로드하고 준비 상태를 확인합니다. |
| 온라인 문장 통번역 | API 제공자·모델·키를 설정하고 문장 및 선택한 참고정보의 외부 전송 범위를 확인합니다. |
| On-통 Live(AI 통역) | 지원되는 실시간 음성 API 모델과 입력·출력 언어를 선택하고 마이크 입력 전송을 허용합니다. |
| 음성노트·파일 인식 | 기기의 인식 엔진, Android 버전과 설치된 언어 자료에 따라 지원 범위가 달라집니다. |

기기 내 모델의 크기와 복수 언어 처리 부담은 메모리·발열·지연에 영향을 줄 수 있습니다. 기기에 맞는 옵션을 선택하고 짧은 실제 발화로 확인하세요. 모든 모델·언어의 성능이 동일하지 않습니다.

On-통 Live(AI 통역)의 전문 지침·참고자료는 모델이 지원하고 사용자가 전송을 허용한 범위에서 적용됩니다. 음성 전용 번역 모델에서 지원하지 않는 텍스트 설정은 앱의 안내를 따르세요. 모델을 바꾸면 전송 허용 범위를 다시 확인합니다.

온라인 모드에서는 제공자 과금과 네트워크 연결이 필요합니다. 요청 수와 보고된 사용량을 확인하되, 제공자가 사용량을 보고하지 않은 경우 무료로 간주하지 마세요.
