# 서비스별 음성 처리와 검증 범위

소스 확인일: 2026-09-21, 0.2.43-alpha. 아래 내용은 구현 경로이며 기기별 정확도·지연 측정값이 아니다.

| 서비스 | 입력·처리 | 결과와 사용 조건 |
| --- | --- | --- |
| 녹톡 | 16-kHz mono PCM WAV 녹음 → Android 온디바이스 파일 인식 → ML Kit 번역 | 원음 재생, 원문·괄호 번역, TXT/SRT/WAV. 파일 인식은 Android 13 이상. 자동 언어 전환 요청은 Android 14 이상이며 엔진·언어팩 지원 필요. |
| 라이브톡 | 선택한 마이크/앱 등에서 받은 원음 PCM을 방송 채널에 전달 | 같은 네트워크의 웹 청취 경로. 번역·합성 준비 성공을 원음 방송 시작 조건으로 삼지 않는다. |
| 통역톡 | 기존 Android/Moonshine 인식, 선택한 ML Kit/Gemma/API 번역과 기존 음성 공급자 | 선택 언어별 준비·실패를 구분한다. 다운로드와 실제 모델 지원 언어·기기 자원이 필요하다. |
| 스크립톡 | 파일 디코더 → 제한된 크기의 PCM 청크 인식 → 선택한 번역 경로 | 파일 시각과 전사·번역을 연결해 읽고 듣는다. 단어 종료 시각과 누락된 단어 시각을 확정값으로 만들지 않는다. |

녹톡은 Moonshine 인식 또는 Gemma 번역으로 자동 전환하지 않는다. 녹음 완료 후 받아쓰며
실시간 받아쓰기·자동 화자 분리·음색 복제는 제공하지 않는다. 수동 화자 이름 지정은 지원한다.
서비스 홈/녹톡/파일 화면에서 통역 방송 모델의 자동 준비가 시작되지 않도록 분리했다.

## 이번에 반영한 안정성 개선

- 녹톡 원문은 번역 준비 전에 먼저 저장한다. 번역 실패 시 저장된 원문과 원음을 유지한다.
- 중단 녹음의 길이를 복구하기 전에 고정 WAV 형식을 확인한다. 형식이 손상된 파일은 변경하지 않는다.
- 음수·역전된 자막 시각을 보정하며 최소 양의 길이를 보장한다. 원본 시각을 정밀 측정값으로 바꾸지는 않는다.
- 구간 재생은 선택 위치에서 시작하며 화면 이탈/경합 작업이 있으면 늦은 자동 재생을 취소한다.
- TXT/SRT와 구간 버튼은 큰 글씨·좁은 화면에서도 접근 가능하도록 배치를 조정했다.

## 기존 모델·라이선스·전송 경계

이번 업데이트는 운영 의존성이나 모델을 추가·교체하지 않는다. 기존 Kokoro/Moonshine/Android
음성 경로와 고정 해시·라이선스 검사를 유지한다. SDK와 모델·음성의 이용 조건은 각각 확인해야 한다.
현재 포함 내역은 [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md)와 앱의 오프라인 라이선스 화면이 기준이다.
실측하지 않은 RTF, 50ms 전송 지연, 모든 기기의 품질·법적 적합성을 보장하는 표현은 사용하지 않는다.

온라인 API는 별도 설정과 동의가 필요한 기존 경로다. 녹톡의 파일 음성 인식은 온디바이스 인식기만
생성하고 번역에는 로컬 ML Kit 경로를 사용한다. 모델 최초 다운로드에는 인터넷이 필요할 수 있다.
사용자 확정 문장 학습은 기기 문장 사전 갱신이며 모델 가중치 재학습이 아니다.

소스·모의 시험·APK·에뮬레이터·물리 휴대폰 결과를 구분해 [TEST_REPORT.md](TEST_REPORT.md)에 기록한다.
