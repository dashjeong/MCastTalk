# 음성노트 설계와 지원 범위

0.2.43의 음성노트 기능과 후속 개선 과제를 구분합니다. 아래 설계 설명은 실제 단말의 품질·지연 측정 결과를 대신하지 않습니다.

| 제안 | 현재 상태와 결정 |
|---|---|
| 앱 안의 독립 음성노트 | 녹톡 서비스로 이미 분리. 방송/TTS를 자동 실행하지 않음 |
| 원문 보존, 수동 수정 보호, 번역 재개 | 이미 구현한 원자 저장·부분 체크포인트·언어 변경 전체 성공 시 교체를 유지 |
| MD/JSON과 내보내기 옵션 | 이번 반영. 문서 전체 복제 없이 Writer에 구간별 출력, WAV 64KB 복사, 취소·디스크 오류 안내 |
| 녹음/전사 처리 상태와 시간 근거 | 번역 미완료 수와 추정 시각 표시. 원래 구간의 `timingEstimated` 저장. 기존 자료는 보수적으로 추정값 처리 |
| 자동 감지 시 언어 추측 금지 | 실제 코드의 파일 대표 언어 대입 문제 수정. 수동 선택과 자동 감지를 분리 |
| 다시 듣기 조작 | ±10초·배속·현재 구간 표시 반영. 구간 반복/북마크는 후속 범위 |
| 녹음과 실시간 전사 동시 처리, 분할 WAV, 일시정지 | 녹음 후 전사라는 현재 서비스 계약 유지. PCM 시간축·오디오 포커스·재시작 복구의 실기기 검증 후 독립 작업으로 추진 |
| Qwen/SenseVoice/Whisper 비교 및 자동 화자분리 | 새 모델 설치·품질 인증을 하지 않음. 엔진별 언어·기기·라이선스·연산 비용을 확인할 실험 과제 |
| 2시간/8시간·정확도/지연 목표 | 실제 시험 결과가 아니므로 미달/통과로 판정하지 않음. 현재 60분 제한 유지 |

JSON 내보내기는 기기 내부 파일 경로를 담지 않는다. 원문/번역 선택은 문서에만 적용하고 WAV는 전체 음성임을 화면에 표시한다. SRT는 형식 호환을 위해 상태 설명을 가짜 자막으로 삽입하지 않고 저장 전 화면에 미완료 상태를 알린다. Markdown의 원문은 HTML·링크·이미지 명령으로 해석되지 않게 이스케이프한다.

시험: 구간 필터와 원래 시간축, 비공개 제외 필드, UTF-8 다국어·이모지, Windows 줄바꿈, 자막 공백, 중단·용량 오류, 최대 2,000개 구간 스트리밍, JSON 실제 파싱, 저장 재개방, 큰 글씨/낮은 화면, MediaPlayer 배속·이동을 검증한다. 실행 결과와 미검증 범위는 [시험 보고서](TEST_REPORT.md)를 확인한다.
