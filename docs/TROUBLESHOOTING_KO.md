문제가 발생하면 먼저 화면의 상태 문구를 확인하고, **입력 → 음성인식 → 번역 → 음성 → 웹 전송** 순서로 점검하세요. 방송 중에는 문제가 없는 채널까지 임의로 초기화하지 않는 것이 좋습니다.

## 빠른 점검

1. 다른 기기에 방송하는 경우 운영자와 청취자가 같은 핫스팟 또는 Wi‑Fi인지 확인합니다. **이 기기에서 사용**은 네트워크 없이 사용할 수 있습니다.
2. 입력 음량계가 움직이는지 확인합니다.
3. 선택한 언어가 **준비됨**인지 확인합니다.
4. 청취자 브라우저에서 **재생**을 직접 누르고 미디어 음량을 올립니다.
5. 별도의 기기 한 대로 처음부터 다시 접속해 봅니다.

## 증상별 해결

| 증상 | 확인할 사항 | 조치 |
| --- | --- | --- |
| QR을 열 수 없음 | 서로 다른 네트워크, 핫스팟 꺼짐, 클라이언트 격리 | 같은 네트워크에 연결하고 VPN을 잠시 끈 뒤 QR을 다시 생성합니다. 공유기의 AP/클라이언트 격리도 확인합니다. |
| PIN이 거부됨 | 숫자 오입력, 만료된 입장 정보, 반복 시도 제한 | 최신 QR을 다시 열고 4~8자리 PIN을 확인합니다. 시도 제한 메시지가 있으면 잠시 후 재시도합니다. |
| 연결됐지만 소리가 없음 | 브라우저 자동 재생 차단, 미디어 음량, 운영자 무음 | **재생**을 직접 누르고 미디어 음량과 이어폰 연결을 확인합니다. 운영자 입력 음량계도 확인합니다. |
| 특정 언어만 나오지 않음 | 해당 언어 모델·음성 미준비 또는 채널 오류 | **언어별 상태**에서 번역과 TTS를 다시 준비하고 시험합니다. 다른 채널은 유지할 수 있습니다. |
| 번역이 시작되지 않음 | 원문과 출력 언어가 같음, 모델 미적용, 메모리 부족 | 서로 다른 언어를 선택하고 모델 준비·자체 점검을 완료합니다. 다른 앱을 종료한 뒤 다시 시험합니다. |
| 입력이 갑자기 멈춤 | 마이크 권한, 화면 잠금, 다른 녹음·통화 앱 | 화면을 켜고 다른 녹음·통화 앱을 종료한 다음 **입력 시작**을 다시 누릅니다. |
| Bluetooth 마이크 음질이 낮음 | 통화용 SCO/헤드셋 프로필 | 정상 동작일 수 있습니다. 품질이 중요하면 USB‑C 마이크 또는 내장 마이크를 시험합니다. |
| 앱 재생음이 무음 | 원본 앱의 캡처 차단, 보호 콘텐츠·통화 음성 | 해당 앱이 제3자 오디오 캡처를 허용하는지 확인합니다. 차단된 음성은 일반 APK에서 우회할 수 없습니다. 물리 입력을 사용하세요. |
| 반복음·삐 소리 | 스피커 소리가 마이크로 재입력 | 즉시 로컬 모니터 음량을 낮추거나 끄고 이어폰을 사용합니다. 마이크와 스피커 거리를 늘립니다. |
| 지연이 계속 증가 | 긴 문장, 언어 수, 기기 자원 부족 | 짧은 문장으로 말하고 동시 언어 수를 줄입니다. 청취자는 **실시간 복귀**를 누릅니다. |
| 모델 다운로드 실패 | 인터넷, 저장 공간, 중단된 다운로드 | 안정적인 인터넷과 저장 공간을 확인한 뒤 다시 누릅니다. 지원되는 경우 이어받기가 진행됩니다. |
| 강사 웹 마이크 권한 거부 | HTTP 페이지, 인증서 미설치, 지문 불일치 | 보안 준비 안내를 따르고 지문이 일치할 때만 로컬 CA를 설치해 HTTPS `/mic` 페이지를 엽니다. |
| 업데이트 설치 실패 | 서명 불일치 또는 더 낮은 버전 | 기존 앱을 삭제하지 말고 배포 담당자에게 새 APK의 서명과 버전을 확인합니다. |

## 현장 복구 순서

1. 운영자가 **방송 일시정지**를 안내합니다.
2. 입력 음량계가 움직이면 입력은 유지하고 문제 언어만 확인합니다.
3. 입력이 없으면 다른 녹음 앱을 종료하고 입력 장치를 다시 선택합니다.
4. 문제 언어의 번역·음성을 다시 준비하고 시험합니다.
5. 별도 청취자 기기로 재생을 확인합니다.
6. 정상 확인 후 방송을 재개합니다.

앱이 응답하지 않더라도 즉시 저장공간 삭제나 재설치를 진행하지 마세요. 교정 기록과 모델이 제거될 수 있습니다.

## 진단 정보 전달

**진단 로그 내보내기**를 사용하고 다음 내용을 함께 전달하면 원인 확인에 도움이 됩니다.

- 실제 설치된 앱 버전(예: `0.2.40-alpha`)
- Android 버전, 기기 제조사와 모델
- 입력·출력 장치명
- 원문 언어와 문제가 난 통역 언어
- 화면에 표시된 오류 문구 전체
- 발생 시각과 재현 순서

진단 로그에는 음성·통역 문장·PIN이 포함되지 않도록 설계되어 있습니다. 그래도 외부에 보내기 전 내용을 확인하세요.

## 0.2.40 추가 기능 점검

| 증상 | 확인과 조치 |
| --- | --- |
| Wi-Fi 없이 혼자 사용하고 싶음 | **사용 방식 → 이 기기에서 사용**을 선택하고 단독 사용을 시작합니다. 모델·언어팩 준비는 먼저 마칩니다. 다른 기기로의 웹 방송에는 공유 네트워크가 필요합니다. |
| 단독 사용 중 QR이 보이지 않음 | 단독 사용은 외부 청취 주소를 열지 않습니다. 참가자에게 공유하려면 중지 후 **다른 기기에 방송**을 선택하세요. |
| 앱 선택과 수동 패키지명이 달라 혼동됨 | 앱을 다시 고르면 패키지명이 채워집니다. 이후 직접 수정한 값이 입력 시작 시 우선합니다. 원본 앱의 캡처 차단은 별도 제한입니다. |
| 파일 변환을 시작할 수 없음 | 입력·방송·실시간 시험을 먼저 중지하고 권한 안내를 확인합니다. 새 음성 인식은 Android 13 이상과 파일 입력을 지원하는 온디바이스 서비스가 필요합니다. |
| 자동 언어를 선택할 수 없거나 감지가 안 됨 | Android 13에서는 원문 언어를 직접 고릅니다. Android 14 이상도 엔진·언어팩 지원에 따라 자동 감지가 불가능할 수 있으므로 수동 언어로 재시도하세요. |
| 여러 파일 중 일부만 실패함 | 완료된 결과는 보존됩니다. 파일 접근·언어팩·모델·저장 공간 문제를 해결한 뒤 **실패 항목 재작업** 또는 **이 파일 재작업**을 누릅니다. |
| 폴더를 선택했는데 일부 파일이 없음 | 지원되는 오디오 파일인지 확인하고, 너무 큰 폴더는 나누어 선택하세요. 공급자의 접근 제한·선택 상한 안내도 확인합니다. |
| 저장된 스크립트의 원음이 재생되지 않음 | **원본 파일 다시 찾기**로 같은 내용의 파일을 선택하세요. 이름만 같고 내용이 다르면 연결할 수 없습니다. 접근할 수 없는 경우 저장된 글은 계속 확인할 수 있습니다. |
| 단어 강조가 없거나 문장 구간만 강조됨 | 인식 엔진이 단어 시각을 제공하지 않은 경우입니다. **시각 추정**은 정밀 경계를 보장하지 않습니다. 스크립트와 원음을 함께 확인하세요. |
| 숫자·처리 시간 같은 상세 표시가 사라짐 | 기술 정보는 **설정 → 개발자 정보 표시**를 켜면 볼 수 있습니다. 오류 안내와 진단 내보내기는 기본 화면에서도 유지됩니다. |
| 의역을 켜도 문체가 같음 | ML Kit 단독 경로에는 문체 조절이 없습니다. 준비된 Gemma가 실제 선택 경로에 사용되는지, 또는 API 키·전송 동의가 있는지 확인하세요. 실시간 API는 자동 학습 후 이후 같은 문장에 적용됩니다. |
| 표현 음성이 기본 음성과 비슷함 | 작은 속도·음정 실험입니다. Android 설치 음성에서 같은 문장을 비교하세요. Moonshine에는 이 조절이 없고 감정 복제는 지원하지 않습니다. |
| API 검토나 자동 학습이 적용되지 않음 | 개발자 표시·키·전송 동의와 실시간일 경우 자동 학습 설정을 확인합니다. 시간 초과·실패·보수적 내용 검사에서는 초안을 유지하며, 사용자 확정 문장은 AI가 덮어쓰지 않습니다. |

문장 확인과 데이터 이동의 범위는 [개발자 실험 및 문장 사전 안내](DEVELOPER_LAB.md)를 참고하세요. 오류 보고에 API 키·개인 원문·원음·파일 접근 주소를 공개하지 마세요. 개발자 표시를 켜야만 진단을 수집하는 것은 아닙니다.

8시간 연속 안정성이나 물리 Galaxy/One UI·야외·Android/iPhone의 결과는 해당 환경을 실제 시험한 기록으로만 판단합니다. 자동·에뮬레이터 시험은 이를 대체하지 않으며, 이번 변경만으로 장시간 사용을 보증하지 않습니다. 자세한 범위는 [시험 보고서](TEST_REPORT.md)를 확인하세요.
