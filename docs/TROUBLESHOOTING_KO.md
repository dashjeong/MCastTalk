# 문제 해결

## 마이크 입력이 없어요

Android의 마이크 권한, 입력 장치 선택, 마이크 사용 중인 다른 앱을 확인하세요.
중계 시작 후 입력 상태와 한국어 원문 표시를 확인하세요. 온라인 통역은 인터넷
연결과 선택한 서비스의 API 키가 필요합니다. Gemini와 OpenAI의 키 설정은 서로
다릅니다. 사용하려는 서비스를 선택한 뒤 키 적용 상태를 확인하세요.

## 통역 음성이 들리지 않아요

기기 음량과 출력 장치, 기기 재생 옵션, 출력 언어와 모델의 음성 지원을 확인하세요.
원문 표시, 번역 표시, 음성 출력은 각각 확인해야 합니다. 자막만 보인다고 음성이
완료된 것은 아닙니다. 모델 오류나 요금·사용 한도 안내가 있으면 확인 후 다시 시작하세요.
오프라인 음성은 해당 언어의 음성 데이터가 설치되어 있어야 합니다.

## 청취 웹페이지에 접속되지 않아요

LAN 청취자 방송을 켜고 중계 시작 후 표시되는 주소 또는 QR을 사용하세요.
휴대폰과 청취 기기가 서로 연결 가능한 네트워크에 있어야 합니다. 공유기의
기기 간 차단, VPN, 방화벽과 선택한 PIN/QR 접근 설정을 확인하세요. 웹페이지에서
언어를 선택한 뒤 듣기를 누르세요. HTTPS 인증서 신뢰는 별도 확인이 필요합니다.

## 전문 분야 자료가 반영되지 않아요

분야, 통역 지침과 자료를 저장하고 사용할 자료를 활성화하세요. 전송 동의와 모델의
프롬프트·참고 자료 지원을 확인하세요. 표시된 발췌 분량과 누락 용어를 검토하세요.
오디오 전용 모델에는 텍스트 자료를 적용할 수 없습니다. 자료 등록만으로 번역
정확도가 보장되는 것은 아닙니다.

## 방송 이력과 내려받기

목록에서 방송을 선택해 스크립트와 재생 가능한 음성을 먼저 확인하세요. 녹음 공백이나
저장 공간 경고가 있으면 해당 구간을 확인하세요. MP3 또는 스크립트 내려받기에서
저장 위치를 선택하세요. 공유는 실제 내용이 포함된 파일을 다른 앱에 전달합니다.

## 오프라인 품질 개선

지원되는 온라인 비교 경로의 후보를 검토하고 승인해야 보정 메모리에 적용됩니다.
Gemini의 모든 Live 모델에서 비교 학습이 지원되는 것은 아닙니다. 승인·활성화 상태를
확인하고 필요하면 되돌리세요. 이 기능은 모델 가중치를 다시 학습하지 않습니다.

문제 제보에는 앱 버전과 재현 순서를 적으세요. API 키, PIN, 사적인 음성·스크립트는
공개하지 마세요. [사용 안내](USER_GUIDE_KO.md) · [보안과 개인정보](../SECURITY.md)
