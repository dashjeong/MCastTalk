문제가 발생하면 먼저 화면의 상태 문구를 확인하고, **입력 → 음성인식 → 번역 → 음성 → 웹 전송** 순서로 점검하세요. 방송 중에는 문제가 없는 채널까지 임의로 초기화하지 않는 것이 좋습니다.

## 빠른 점검

1. 운영자와 청취자가 같은 핫스팟 또는 Wi‑Fi인지 확인합니다.
2. 입력 음량계가 움직이는지 확인합니다.
3. 선택한 언어가 **준비됨**인지 확인합니다.
4. 청취자 브라우저에서 **재생**을 직접 누르고 미디어 음량을 올립니다.
5. 별도의 기기 한 대로 처음부터 다시 접속해 봅니다.

## 증상별 해결

| 증상 | 확인할 사항 | 조치 |
| --- | --- | --- |
| QR을 열 수 없음 | 서로 다른 네트워크, 핫스팟 꺼짐, 클라이언트 격리 | 같은 네트워크에 연결하고 VPN을 잠시 끈 뒤 QR을 다시 생성합니다. 공유기의 AP/클라이언트 격리도 확인합니다. |
| PIN이 거부됨 | 숫자 오입력, 만료된 입장 정보, 반복 시도 제한 | 최신 QR을 다시 열고 4~8자리 PIN을 확인합니다. 시도 제한 메시지가 있으면 잠시 후 재시도합니다. |
| 연결됐지만 소리가 없음 | 브라우저 자동 재생 차단, 미디어 음량, 운영자 무음 | **재생**을 직접 누르고 미디어 음량과 이어폰 연결을 확인합니다. 운영자 입력 음량계도 확인합니다. |
| 특정 언어만 나오지 않음 | 해당 언어 모델·음성 미준비 또는 채널 오류 | **언어별 상태**에서 번역과 TTS를 다시 준비하고 시험합니다. 다른 채널은 유지할 수 있습니다. |
| 번역이 시작되지 않음 | 원문과 출력 언어가 같음, 모델 미적용, 메모리 부족 | 서로 다른 언어를 선택하고 모델 준비·자체 점검을 완료합니다. 다른 앱을 종료한 뒤 다시 시험합니다. |
| 입력이 갑자기 멈춤 | 마이크 권한, 화면 잠금, 다른 녹음·통화 앱 | 화면을 켜고 다른 녹음·통화 앱을 종료한 다음 **입력 시작**을 다시 누릅니다. |
| Bluetooth 마이크 음질이 낮음 | 통화용 SCO/헤드셋 프로필 | 정상 동작일 수 있습니다. 품질이 중요하면 USB‑C 마이크 또는 내장 마이크를 시험합니다. |
| 앱 재생음이 무음 | 원본 앱의 캡처 차단, 보호 콘텐츠·통화 음성 | 해당 앱이 제3자 오디오 캡처를 허용하는지 확인합니다. 차단된 음성은 일반 APK에서 우회할 수 없습니다. 물리 입력을 사용하세요. |
| 반복음·삐 소리 | 스피커 소리가 마이크로 재입력 | 즉시 로컬 모니터 음량을 낮추거나 끄고 이어폰을 사용합니다. 마이크와 스피커 거리를 늘립니다. |
| 지연이 계속 증가 | 긴 문장, 언어 수, 기기 자원 부족 | 짧은 문장으로 말하고 동시 언어 수를 줄입니다. 청취자는 **실시간 복귀**를 누릅니다. |
| 모델 다운로드 실패 | 인터넷, 저장 공간, 중단된 다운로드 | 안정적인 인터넷과 저장 공간을 확인한 뒤 다시 누릅니다. 지원되는 경우 이어받기가 진행됩니다. |
| 강사 웹 마이크 권한 거부 | HTTP 페이지, 인증서 미설치, 지문 불일치 | 보안 준비 안내를 따르고 지문이 일치할 때만 로컬 CA를 설치해 HTTPS `/mic` 페이지를 엽니다. |
| 업데이트 설치 실패 | 서명 불일치 또는 더 낮은 버전 | 기존 앱을 삭제하지 말고 배포 담당자에게 새 APK의 서명과 버전을 확인합니다. |

## 현장 복구 순서

1. 운영자가 **방송 일시정지**를 안내합니다.
2. 입력 음량계가 움직이면 입력은 유지하고 문제 언어만 확인합니다.
3. 입력이 없으면 다른 녹음 앱을 종료하고 입력 장치를 다시 선택합니다.
4. 문제 언어의 번역·음성을 다시 준비하고 시험합니다.
5. 별도 청취자 기기로 재생을 확인합니다.
6. 정상 확인 후 방송을 재개합니다.

앱이 응답하지 않더라도 즉시 저장공간 삭제나 재설치를 진행하지 마세요. 교정 기록과 모델이 제거될 수 있습니다.

## 진단 정보 전달

**진단 로그 내보내기**를 사용하고 다음 내용을 함께 전달하면 원인 확인에 도움이 됩니다.

- 앱 버전: `0.2.39-alpha`
- Android 버전, 기기 제조사와 모델
- 입력·출력 장치명
- 원문 언어와 문제가 난 통역 언어
- 화면에 표시된 오류 문구 전체
- 발생 시각과 재현 순서

진단 로그에는 음성·통역 문장·PIN이 포함되지 않도록 설계되어 있습니다. 그래도 외부에 보내기 전 내용을 확인하세요.
