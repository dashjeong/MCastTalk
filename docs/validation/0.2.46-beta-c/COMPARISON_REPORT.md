# 0.2.46-beta-c 품질검증 및 개선 결과

2026-10-01. Codex가 최종 APK의 네이티브 시험을 실행하고, Antigravity의 Gemini
참조 번역·비교 검토를 원시 결과와 대조했다. **베타 검증 결과이며 상용 품질 인증이 아니다.**
원문 의미가 판단 기준이고 Gemini 번역도 정답으로 간주하지 않았다.

## 대상과 증빙

- 사용자 제공 한국어 IR 기사 22문장 × 영어·일본어·중국어 간체 = 66건.
- 최종 APK SHA-256: `b73844cad224e733ccea843cbcb1d47b9d56494b82c118e4d16a6c7d9a4bd330`.
- API 35 ARM64 에뮬레이터, 실제 로컬 E4B 추론. 동일 모델·원문·AUTO 어체 사용.
  기사 비교에는 신규 양언어 메모리를 넣지 않았다. Gemini 결과를 E4B에 주입하지 않았다.
- [전체 비교 JSON](comparison.json), [CSV](comparison.csv), [최종 원시 결과](e4b-final.json),
  [기존 결과](e4b-baseline.json), [Gemini 참조](gemini-reference.json), [원문](ir-corpus.json).
- 별도 녹음 음성·운영 송출·설치·서명 시험은 [시험 보고서](../../TEST_REPORT.md)에 기록했다.
  기사 시험은 텍스트 입력이므로 음성 인식 구간화 또는 발음 평가를 대신하지 않는다.

## 비교 판정

PASS는 이 표본에서 의미상 문제를 발견하지 못한 경우, MINOR는 국소적 표현·경계·
고유명사 확인 문제, MAJOR는 핵심 사건 시제나 수식 대상 등 의미 관계가 달라진 경우다.
NO_OUTPUT은 실행 실패이며 오역과 분리했다. 이 등급은 Codex/Antigravity의 AI 보조 검토이며
독립적인 이중언어 전문가 검수나 일반적인 정확도 수치가 아니다. 원시 번역은 수정하지 않았다.

| 구분 | PASS | MINOR | MAJOR | 미출력 |
| --- | ---: | ---: | ---: | ---: |
| 기존 정책 | 46 | 13 | 6 | 1 |
| 최종 후보 | 52 | 11 | 3 | 0 |

등급 유지 59건, 의미 등급 개선 6건, 미출력 회복 1건, 등급 하락 0건이다.
미출력은 IR16-영어로 기존 **10,007ms** 후 예외가 발생했다. 120초라는 초기 검토 문구는
원시 측정값과 맞지 않아 교정했다. 등급 유지가 동일한 번역이나 무오류를 뜻하지 않는다.
최종 자연스러움 검토는 64 PASS, 2 MINOR이며 사람의 청취·번역 인증은 아니다.

남아 있는 문제는 다음과 같다. 서로 다른 문제를 중복 합산하지 않고 문장·언어별로 14건이다.

- **MAJOR 3건:** IR02 영어·중국어의 이미 개최한 행사에 미래 시제 사용,
  IR03 영어의 창업자에 관한 수식이 투자자에게도 적용되는 오류.
- **MINOR 11건:** IR01 영어·중국어 및 IR05 영어의 ‘이상’ 경계,
  IR09 영어의 개최 횟수 해석 모호성, IR10/13/15/17/18 영어의 원문에 없는 ‘We’,
  IR13/18 영어의 프로그램·브랜드 표기, IR22 중국어 기관명 축약,
  IR22 일본어·중국어의 공식 한자 미확인 인명. 미확인 인명은 오역으로 확정하지 않았다.

## 실제 반영과 회귀 방지

E2B/E4B 선택을 유지하고, E4B에 원문 기반 숫자 경계·기관명·투자 유치·지역 정책 용어를
보조한다. 기존 문장 확정 기준과 PCM 재생 순서는 변경하지 않았다. 방송별로 최근 성공한
원문/번역 쌍을 짧게 보관하며 종료 시 비운다. 디스크 저장·외부 전송·모델 가중치 학습은 없다.

빠른 프롬프트 후보는 기사 66건 실행에 성공했지만 실제 음성 회귀에서 2/4 실패했다.
따라서 해당 APK를 폐기하고 기존 프롬프트와 어체 지시를 복구했다. 최종 23개 음성 보정
대조 출력은 beta-b와 모두 같고 강화된 의미 회귀 검사를 통과했다. 기존의
**20 PASS / 2 WARN / 1 FAIL(C2 사역 의미)** 판정은 그대로 남아 있다.

별도 [문맥·구문 30건](syntax-final.json)은 전부 실행됐고 검토한 핵심 의미가 보존됐다.
27건의 비어 있지 않은 메모리 후보는 예산 이내였다. 숫자 ‘미만’, 한국 부처명,
앞선 명칭과 다음 문장 관계를 확인했다. 메모리 OFF 대조군이 없어 메모리 자체의
정확도 개선 효과는 입증하지 않았다. 전체 데이터 수명·취소·언어 분리는 단위시험으로 확인했다.

## 속도와 한계

| 번역 언어 | 기존 중앙값 | 최종 중앙값 | 최종 표본 p95 |
| --- | ---: | ---: | ---: |
| 영어 | 4,607 ms | 3,827.5 ms | 5,806 ms |
| 일본어 | 4,953.5 ms | 4,107.5 ms | 6,052 ms |
| 중국어 간체 | 4,446.5 ms | 3,747.5 ms | 5,371 ms |

영어 기존 값은 완료한 21건, 나머지는 각 22건의 단일 실행 표본이다. 영어 미출력 시간은
성공 지연 통계에서 제외했다. 에뮬레이터의 텍스트 번역 중앙값은 약 16~17% 낮아졌으나
통계적 유의성·기능별 인과 효과·실기기 속도를 입증하지 않는다.

실제 운영 경로의 최종 문장 확정→첫 음성 PCM은 **5,205ms**였다. beta-b의 단일 표본
5,117ms보다 빨라지지 않았다. 번역 계산, 음성 합성, 출력 큐 비용이 매 문장에 남으므로
첫 문장 이후 지연이 없어진다고 약속할 수 없다. Galaxy S23 p95 2,000ms 기준,
Samsung/Google 실제 언어팩 설치, 사람의 음성 자연스러움, 2시간/8시간 연속 시험은 미입증이다.
이 결과만으로 무오역·무지연 또는 상용 수준 달성을 홍보해서는 안 된다.
