# MCastTalk 사용 안내

[English](USER_GUIDE_EN.md) · [APK 다운로드](https://github.com/dashjeong/MCastTalk/releases) · [문제 해결](TROUBLESHOOTING_KO.md)

Android 11 이상 ARM64 기기에 설치합니다. APK와 같은 릴리스의 SHA-256을 비교하세요. 통역 품질과 지연은 언어, 모델, 기기와 네트워크에 따라 달라집니다.

## 통역 방식 선택

- 기기 내 통번역: 사용할 인식·번역 모델과 음성을 미리 준비합니다. 준비가 끝나면 인터넷 없이 사용할 수 있습니다.
- 온라인 문장 통번역: 음성을 문장으로 인식한 뒤 선택한 API로 번역하고 음성으로 출력합니다.
- 통역 중계: 마이크 음성을 선택한 실시간 API에 보내 통역 음성과 자막을 받습니다. 인터넷 연결, API 키와 전송 동의가 필요하며 제공자 요금이 발생할 수 있습니다.

표시되는 모델·언어와 전송 허용 범위를 확인하세요. API 키는 앱 설정에 입력하고 공개 게시물이나 공유 파일에 포함하지 마세요.

## 방송과 청취

1. 마이크 권한을 허용하고 입력·출력 언어를 선택합니다. 기기 내 통역은 모델과 음성의 준비 상태도 확인합니다.
2. 청취자를 같은 Wi-Fi 또는 핫스팟에 연결합니다. 공유기의 기기 간 통신 차단 설정이 켜져 있으면 접속할 수 없습니다.
3. 방송을 시작합니다. 통역 중계에서는 ‘LAN 청취자에게 방송’을 켭니다.
4. 화면에 표시된 청취 주소를 복사·공유하거나 QR을 보여줍니다. 주소에 포함된 접속 정보를 함께 전달해야 합니다.
5. 청취자는 브라우저에서 접속하고 듣기를 누릅니다. 제공되는 언어·원음·통역 음성·자막 옵션을 선택합니다.

기기 스피커나 청취자의 소리가 마이크로 다시 들어오면 반복 통역이 생길 수 있습니다. 이어폰을 사용하고 원문·번역·음성을 확인한 뒤 운영하세요. 로컬 주소는 같은 네트워크에서 사용하며, 인터넷 공개 중계에는 별도의 연결 환경이 필요합니다.

## 전문 분야와 참고자료

지원되는 통역 중계 모델에서는 ‘전문 분야·내 통역 지침’에서 분야와 통역 지침을 입력·저장할 수 있습니다. 참고자료에 강의·글·용어집을 등록하고 사용할 자료를 선택합니다. 미리보기에서 실제 전송 범위를 확인하세요. 자료 전체가 매번 전송되는 것은 아닙니다.

음성 전용 번역 모델은 별도 지침이나 텍스트 참고자료를 지원하지 않을 수 있습니다. 앱의 모델별 안내를 확인하고, 허용 범위가 바뀌면 전송 동의를 다시 확인합니다. 개인정보·비밀정보가 포함된 자료는 외부 전송 전에 제거하세요.

## 방송 이력과 내려받기

‘방송 이력’에서 방송을 선택하면 저장된 원문·번역 스크립트와 음원을 확인할 수 있습니다. 저장된 음원을 선택해 재생한 뒤 MP3를 내려받거나 공유합니다. 전체 스크립트는 TXT로 내려받을 수 있습니다. 기기 내 음성노트와 방송 이력은 각각 해당 메뉴에서 관리합니다.

삭제하거나 다른 버전으로 바꾸기 전에 필요한 자료를 백업하세요. 공유할 음원과 스크립트에 다른 사람의 개인정보가 포함되지 않았는지 확인합니다.

## 품질 개선과 제한

온라인·오프라인 비교 결과를 검수해 적용하는 기능은 지원되는 경로와 준비된 오프라인 모델이 필요합니다. 교정 사례를 참고하는 기능이며 모델 가중치를 자동 학습한다는 의미는 아닙니다. 적용과 되돌리기 상태를 확인하세요. 음성 중계 지원과 비교학습 지원은 모델별로 다를 수 있습니다.

오인식·번역 오류·통역 지연이 발생할 수 있습니다. 기기와 환경에서 실제 발화·청취를 확인하고 사용하세요. HTTP 청취 방송은 암호화되지 않으므로 신뢰할 수 있는 네트워크에서 사용합니다. 문제가 생기면 방송 상태와 모델·언어 설정을 확인하고 [문제 해결](TROUBLESHOOTING_KO.md)을 참고하세요.
