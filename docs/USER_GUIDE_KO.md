# MCastTalk 사용 안내

[English](USER_GUIDE_EN.md) · [APK 다운로드](https://github.com/dashjeong/MCastTalk/releases) · [문제 해결](TROUBLESHOOTING_KO.md)

Android 11 이상 ARM64 기기에 설치합니다. APK와 같은 릴리스의 SHA-256을 비교하세요. 통역 품질과 지연은 언어, 모델, 기기와 네트워크에 따라 달라집니다.

## 통역 방식 선택

- 기기 내 통번역: 사용할 인식·번역 모델과 음성을 미리 준비합니다. 준비된 기기 내 모델로 음성을 처리합니다.
- 온라인 문장 통번역: 음성을 문장으로 인식한 뒤 선택한 API로 번역하고 음성으로 출력합니다.
- 통역 중계: 마이크 음성을 선택한 실시간 API에 보내 통역 음성과 제공되는 자막을 받습니다. 인터넷 연결, API 키와 전송 동의가 필요하며 제공자 요금이 발생할 수 있습니다.

표시되는 모델·언어와 전송 허용 범위를 확인하세요. API 키는 앱 설정에 입력하고 공개 게시물이나 공유 파일에 포함하지 마세요.

통역 중계는 기본 5개 언어를 먼저 보여주며, 더보기·검색에서 75개 언어·지역 선택지를 찾을 수 있습니다. 발화 언어 1개와 통역 언어 최대 5개를 선택합니다. 목록에 있다고 모든 모델의 음성·자막 지원과 품질이 보장되지는 않습니다. 통역 언어마다 별도 API 연결을 사용하므로 언어 수에 따라 비용이 늘어날 수 있습니다. 제공자가 번역 자막을 보내지 않으면 앱의 자막 없음 안내를 확인하세요.

## 방송과 청취

1. 사용할 메뉴를 선택합니다. 공통 환경은 ‘설정’, 해당 작업의 환경은 ‘이 메뉴 설정’에서 준비합니다. 음성 입력을 사용할 때 마이크 권한과 입력·출력 언어를 확인합니다. 기기 내 처리를 선택했다면 사용할 모델·음성을 준비합니다.
2. 청취자를 같은 Wi-Fi 또는 핫스팟에 연결합니다. 공유기의 기기 간 통신 차단 설정이 켜져 있으면 접속할 수 없습니다.
3. 해당 메뉴에서 웹 방송을 시작합니다. 마이크 켜기·끄기는 별도로 제어하며, 마이크를 켰다는 것만으로 청취자에게 방송되지 않습니다. 통역 중계에서는 LAN 청취자 방송 설정을 확인합니다.
4. 화면에 표시된 청취 주소를 복사·공유하거나 QR을 보여줍니다. 주소에 포함된 접속 정보를 함께 전달해야 합니다.
5. 청취자는 브라우저에서 접속하고 듣기를 누릅니다. 제공되는 언어·원음·통역 음성·자막 옵션을 선택합니다. 음성이 준비 중이거나 방송이 일시정지됐으면 페이지의 상태 안내를 확인합니다.

기기 스피커나 청취자의 소리가 마이크로 다시 들어오면 반복 통역이 생길 수 있습니다. 이어폰을 사용하고 원문·번역·음성을 확인한 뒤 운영하세요. 로컬 주소는 같은 네트워크에서 사용하며, 인터넷 공개 중계에는 별도의 연결 환경이 필요합니다.

## 전문 분야와 참고자료

지원되는 통역 중계 모델에서는 ‘전문 분야·내 통역 지침’에서 분야와 통역 지침을 입력·저장할 수 있습니다. 참고자료에 강의·글·용어집을 등록하고 사용할 자료를 선택합니다. 미리보기에서 실제 전송할 발췌를 확인하고 사용을 허용하세요. 자료 전체가 매번 전송되는 것은 아닙니다.

지침·텍스트 참고자료 지원 여부는 모델마다 다릅니다. 앱의 모델별 안내를 확인하고, 전송 범위가 바뀌면 동의를 다시 확인합니다. 개인정보·비밀정보가 포함된 자료는 외부 전송 전에 제거하세요.

## 방송 이력과 내려받기

‘방송 이력’에서 방송을 선택하면 저장된 원문·번역 스크립트와 음원을 확인할 수 있습니다. 저장된 음원을 선택해 재생한 뒤 MP3를 내려받거나 공유합니다. 전체 스크립트는 TXT로 내려받을 수 있습니다. 기기 내 음성노트와 방송 이력은 각각 해당 메뉴에서 관리합니다.

웹 방송의 다시 듣기에서도 저장된 스크립트를 확인할 수 있습니다. HUD의 저장 스크립트는 음성과 자동으로 시간 동기화되지 않습니다.

삭제하거나 다른 버전으로 바꾸기 전에 필요한 자료를 백업하세요. 공유할 음원과 스크립트에 다른 사람의 개인정보가 포함되지 않았는지 확인합니다.

## 품질 개선과 제한

지원되는 경로에서는 온라인·오프라인 비교 결과를 검수·승인한 교정 사례를 참고합니다. 준비된 오프라인 모델이 필요하며, 모델 가중치를 다시 학습하지 않습니다. 적용과 되돌리기 상태를 확인하세요. 음성 중계와 비교·교정 지원 범위는 모델별로 다릅니다.

오인식·번역 오류·통역 지연이 발생할 수 있습니다. 기기와 환경에서 실제 발화·청취를 확인하고 사용하세요. HTTP 청취 방송은 암호화되지 않으므로 신뢰할 수 있는 네트워크에서 사용합니다. 문제가 생기면 방송 상태와 모델·언어 설정을 확인하고 [문제 해결](TROUBLESHOOTING_KO.md)을 참고하세요.
