# 마지막 문장 무음 확정 회귀 기록

대상: 0.2.46-beta-d 후보. 마지막 원문이 다음 발화가 들어올 때까지 번역되지 않는 증상.

## 원인과 변경

문장 경계 판정이 일부 한국어 구어체 명령형을 종결로 인정하지 않았다. 미완성으로
분류된 끝부분에는 실제 무음이 오래 지속되어도 처리 상한이 없어 대기가 계속됐다.
또한 무음으로 이미 확정한 provider partial에 늦은 수정 final이 도착하면 잔여 단어를
별도 번역할 여지가 있었다.

- 명확한 구어체 종결을 추가했다. 완결문은 기존 문장·안정성·무음 기준을 사용한다.
- 제품 정책에서 실제 연속 무음 8,000ms와 가설 안정 500ms를 함께 확인하면 남은
  usable 원문 전체를 한 번 확정한다. 기존의 빈 값·의미 없는 기호 필터는 유지한다.
  단어 삭제, 문장 보완, 열린 인용부호 자동 닫기를 하지 않는다.
- 8초는 문장마다 기다리는 시간이 아니라 미완성 판정의 최후 상한이다. 짧은 부정·연결절
  쉼은 보존하며, 계속 말하는 중에는 이 상한이 음성을 잘라내지 않는다.
- 무음 길이는 연속 PCM 캡처 시각으로 잰다. 프레임 누락이나 실행 스케줄 지연을
  추가 무음으로 계산하지 않는다.
- 확정한 provider 구간을 종료 표시해 늦은 final의 중복 출력을 차단한다. 새 발화가
  동일한 provider ID에 추가되어도 이미 처리한 prefix를 제외하고 다음 내용을 유지한다.
- 입력과 방송을 닫거나 자동 중지하지 않는다. 기존 별도 ticker가 확정 결과를 전달한다.

이 정책은 입력 음성이 끝난 시점의 결정 상한이며, 번역 모델·TTS 실행 시간을 포함한
최종 출력 지연 보장은 아니다. 번역 및 첫 PCM 지연은 별도로 측정한다.

## 회귀 범위

`IdleSentenceCompletionRegressionTest`는 콜백이 더 오지 않는 단일 구어체 가설,
늦은 수정 final, 다음 provider 줄의 순서, 800ms 캡처 지연, 연속 발화, PCM 누락,
짧은 부정·연결절 쉼, 중지 후 재개, 8초 상한, 열린 인용, 최근 가설 변경,
동일 provider ID의 다음 발화를 검사한다.

기존의 긴 미완성 구절 보존 시험은 명시적인 엄격 정책(상한 OFF)으로 유지한다.
제품 기본 정책의 8초 상한은 별도 시험으로 검사한다. 이는 최신 사용자 요청에 따른
정책 변경이며, 기존 시험을 삭제하거나 오역 판정 기준을 완화한 변경이 아니다.

실기기 회귀 `lastE4bSentenceTranslatesWhileInputRemainsOpenWithoutNextSpeech`는 공개
FLEURS 한국어 PCM 한 문장을 실제 native STT에 자연 속도로 공급한 뒤 입력을 계속
열어 두고 무음만 공급한다. 10초 안의 final, 실제 E4B 번역, 의미 보존, 입력 유지가
합격 조건이다. 이 시험은 마이크의 TV 음성 분리나 TTS 청취 품질을 증명하지 않는다.

실행 결과는 `docs/TEST_REPORT.md`와 해당 증빙 로그에 기록한다. 시험 정의 자체를
실행·통과 증거로 간주하지 않는다.

## 실제 실행 결과 (2026-10-02)

Galaxy S23+ SM-S916N/API 36에서 같은 공개 PCM을 실제 native STT와 E4B로 실행했다.
최종 navigation 후보 APK(SHA-256 `1d097af80de6be6a53727885f055e38ae1b39d1017bc9f4458699df56c92a59e`)에서
시험 1건이 37.215초에 통과했다. 다음 발화 없이 입력이 열린 상태에서 마지막 PCM 발화 종료
561ms 후 문장이 확정되고, 이후 E4B 텍스트 번역에는 2,781ms가 걸렸다.
이전 후보의 568ms/2,963ms 결과와 구분한다.

문장 무한 대기 회귀는 통과했으나 번역 속도·첫 음성 2초 기준까지 통과했다는 의미는 아니다.
독립 20표본 native 첫 PCM p95는 2,041ms로 기준을 초과했다. 실제 웹 첫 PCM 기준과
주변 음성 분리는 이 시험으로 입증하지 않았다. 명령·환경·원음 출처·해시는 TEST_REPORT에 기록했다.
