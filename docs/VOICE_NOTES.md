# 음성노트와 서비스 홈 — 0.2.43 개발 업데이트

2026-09-21, 공개 main `efb254d8d6246f894ac53b04048d628fdb437986` 기반.
요구사항: [공유 기획 대화](https://chatgpt.com/share/6ab11729-6638-83ee-b652-764faa1c7f6a)와
사용자의 네 서비스 구분 및 **녹톡 · 라이브톡 · 통역톡 · 스크립톡** 최종 명명 지시.

## 서비스 선택

앱을 열면 작업 목적에 따라 다음 중 하나를 선택합니다.

| 서비스 | 할 수 있는 일 | 작업 범위 |
|---|---|---|
| 녹톡 · 음성노트 | 새 녹음, 받아쓰기, 괄호 번역, 저장·재생·내려받기 | 개인 기록 |
| 라이브톡 · 원음 방송 | 입력 음성을 청취자에게 송출, QR·접속 관리 | 원음 방송 |
| 통역톡 · 다국어 방송 | 여러 언어로 통역 음성·자막 송출, HUD | 통역 방송 |
| 스크립톡 · 파일 전사 | 기존 파일 일괄 변환·번역, 스크립트를 보며 재생 | 파일 작업 |

방송 서비스에는 운영·시험·설정 탭이 있습니다. 다국어 방송은 언어·모델을
준비하고 통역을 활성화해야 시작할 수 있습니다. 준비가 안 됐다고 원음 방송으로
자동 시작하지 않습니다. 진행 중인 방송에서 서비스 홈으로 돌아와도 방송은
유지되고, 진행 중인 서비스로 돌아가는 버튼이 표시됩니다. 다른 서비스는 작업을
중지한 뒤 열 수 있습니다. 홈 화면으로 이동하는 것만으로 녹음이나 방송이 시작되지는 않습니다.

## 음성노트 사용

1. 서비스 홈 → **녹톡**에서 제목, 말하는 언어, 번역 언어를 고릅니다.
2. **새 녹음 시작**을 누르고 마이크 권한을 허용합니다.
3. **녹음 종료·저장**을 누릅니다. 녹음 파일이 먼저 보관됩니다.
4. **받아쓰기·번역 시작**을 누르면 녹음 전체를 구간별로 인식하고 번역합니다.
5. `원문` 다음 줄에 `(번역문)`이 표시됩니다. 같은 언어·같은 문장은 중복 표시하지 않습니다.
6. 녹음을 재생하거나 위치를 옮겨 원문과 대조합니다. 구간에 화자 이름을 직접 지정할 수 있습니다.
7. **TXT 내려받기**, **SRT 내려받기**, **녹음 내려받기**로 원하는 문서 위치에 저장합니다.

받아쓰기 실패 시 원음은 유지됩니다. 번역 실패 시 완료된 원문도 유지됩니다.
다시 받아쓰기는 성공한 새 원문으로 기존 스크립트·번역·화자 이름을 교체하므로
실행 전에 화면에서 확인합니다. 앱 프로세스가 갑자기 종료된 노트는 보관함에서
열고 **중단된 녹음 복구**로 디스크에 남은 PCM과 WAV 헤더를 복구할 수 있습니다.

## 지원 범위

- 녹음·재생·WAV 내보내기: 앱의 기존 Android 11 이상 범위. 실제 기기 시험 필요.
- 녹음 후 받아쓰기: Android 13 이상 및 온디바이스 음성 인식 서비스/오프라인 언어팩 필요.
- 자동 언어 전환: Android 14 이상에서 한국어·영어·일본어·중국어로 제한해 요청합니다.
  서비스가 기능을 지원해야 하며, OS 버전만으로 지원을 보장하지 않습니다.
  언어 미확인·모델 전환 실패 시 직접 언어를 고르고 다시 시도하도록 안내합니다.
- 구간별 인식 언어를 유지하고 해당 원문에서 선택한 언어로 번역합니다.
  한 문장 안의 혼합 언어, 겹쳐 말하기, 소음 속 정확도는 미검증입니다.
- 자동 화자 분리는 제공하지 않습니다. 화자 이름은 사용자가 구간별로 지정합니다.
- 녹음 중 실시간 전사는 제공하지 않으며, 녹음 완료 후 처리합니다.
- 앱을 벗어나거나 화면을 잠그면 녹음을 종료·저장하고 변환·재생을 중지합니다.
  녹음/변환 화면은 자동 화면 꺼짐을 방지합니다. 백그라운드 장시간 녹음은 미지원입니다.
- 한 노트 최대 60분, 보관함 최대 500개, 노트 최대 2,000개 구간·4 MiB 메타데이터입니다.
  PCM WAV는 분당 약 1.92 MB입니다. 저장 공간이 부족하면 중지합니다.
- SRT 시각은 인식 엔진의 구간 추정값을 포함하므로 자막 편집 시 원음과 확인해야 합니다.

## 데이터와 모델

음성과 노트는 앱 전용 `files/voice-notes`에 저장합니다. 방송 HTTP 서버나 진단
내보내기로 공개하지 않습니다. 사용자가 선택한 문서 위치로만 내보냅니다.
이 노트 저장소는 기존 설정/스크립트 통합 백업에 포함되지 않습니다. 앱 제거 전
필요한 TXT/SRT/WAV 파일을 각각 내려받으세요.

음성 인식은 Android의 온디바이스 인식기, 번역은 기존 ML Kit 경로를 재사용합니다.
음성노트는 API 번역과 개발자 클라우드 검토를 호출하지 않습니다. 최초 번역 모델
다운로드에는 인터넷이 필요할 수 있습니다. 모델 준비 후 추론은 기기 안에서 수행합니다.
새 ASR/화자 분리 모델을 검증 없이 번들하거나 최고 성능이라고 표시하지 않습니다.

기술 근거: [Android RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent),
[SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer).

## 후속 실기기 수용 시험

Android 13 수동 언어, Android 14 이상 자동 전환을 각각 확인합니다. 한국어→영어→일본어→중국어
녹음, 언어팩 누락, 인식 서비스 미지원, 잡음/겹침, 마이크 거부, 저장 공간 부족,
화면 잠금, 강제 종료 후 복구, 방송 중 서비스 전환, TXT/SRT/WAV 재열기를 시험합니다.
실제 화자 분리 모델은 동일 기기에서 메모리·지연·화자 오류와 재배포 조건을 확인한 뒤
별도 기능으로 도입합니다. 이 개발 업데이트는 그 품질 검증을 완료했다고 주장하지 않습니다.
