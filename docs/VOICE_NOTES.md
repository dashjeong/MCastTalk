# 음성노트와 서비스 홈 — 0.2.45 Beta

기능별 실행 결과와 미검증 환경은 [시험 보고서](TEST_REPORT.md)를 확인하세요.
철회된 0.2.43의 요구 누락과 보수 이력은 [이전 보수 기록](MAINTENANCE_0_2_43.md)에 남아 있습니다.

## 서비스 선택

앱을 열면 작업 목적에 따라 다음 중 하나를 선택합니다.

| 서비스 | 할 수 있는 일 | 작업 범위 |
|---|---|---|
| 실시간 방송·통역 | 원음 및 선택 언어의 음성·자막 송출, QR·접속 관리, HUD | 방송·통역 |
| 음성노트 | 녹음 중 받아쓰기, 문장 수정·번역, 저장·재생·내려받기 | 개인 기록 |
| 파일 변환·재생 | 기존 파일 일괄 변환·번역, 스크립트를 보며 재생 | 파일 작업 |

방송 서비스에는 운영·시험·설정 탭이 있습니다. 다국어 방송은 언어·모델을
선택하고 통역을 활성화합니다. 모델 준비 경고가 방송 시작을 대신 결정하지 않습니다.
진행 중인 방송에서 서비스 홈으로 돌아와도 방송은
유지되고, 진행 중인 서비스로 돌아가는 버튼이 표시됩니다. 다른 서비스는 작업을
중지한 뒤 열 수 있습니다. 홈 화면으로 이동하는 것만으로 녹음이나 방송이 시작되지는 않습니다.

## 음성노트 사용

1. 홈 → **음성노트**에서 **녹음·받아쓰기 시작**을 누르고 마이크 권한을 허용합니다.
   선택 언어의 모델 준비가 끝난 뒤 녹음이 시작되고 인식 내용이 본문에 나타납니다.
   시작 전 언어·녹음만 옵션은 **⋮ → 상세보기**에 있습니다. 기본 언어는 지원되는 기존 설정을 사용합니다.
2. 이전 문장을 읽기 위해 스크롤하면 자동 따라가기를 멈춥니다. 아래쪽 복귀 버튼으로 실시간 위치로 돌아갑니다.
3. 아래에 유지되는 **녹음 종료·저장**으로 녹음과 확정된 문장을 보관합니다.
4. 저장된 노트는 본문과 **녹음 재생 / 일시정지**를 기본으로 보여줍니다.
   **⋮ → 번역문 표시**를 선택하면 저장된 번역을 원문 아래에 보여줍니다.
5. **⋮ → 상세보기**에서 구간 시각, 화자 이름, **문장 수정**, **여기서 듣기**를 사용합니다.
6. **⋮ → 노트 도구**에서 언어 선택, 남은 구간 번역, 다시 받아쓰기, TXT·SRT·Markdown·JSON·WAV
   내보내기와 백업·가져오기를 실행합니다. 뒤로 또는 **⋮ → 문장 보기**로 본문에 돌아옵니다.

실시간 받아쓰기가 모든 구간의 번역까지 완료했다는 뜻은 아닙니다. 번역이 없는 구간은
노트 도구의 **남은 구간 번역**으로 처리합니다. 기본 보기에서도 오류와 복구 안내는 유지됩니다.

받아쓰기 실패 시 원음은 유지됩니다. 번역 실패 시 완료된 원문도 유지됩니다.
다시 받아쓰기는 성공한 새 원문으로 기존 스크립트·번역·화자 이름을 교체하므로
실행 전에 화면에서 확인합니다. 앱 프로세스가 갑자기 종료된 노트는 보관함에서
열고 **중단된 녹음 복구**로 디스크에 남은 PCM과 WAV 헤더를 복구할 수 있습니다.

## 지원 범위

- 녹음·재생·WAV 내보내기: 앱의 기존 Android 11 이상 범위. 실제 기기 시험 필요.
- 녹음 후 받아쓰기: Android 13 이상 및 온디바이스 음성 인식 서비스/오프라인 언어팩 필요.
- 자동 언어 전환: Android 14 이상에서 한국어·영어·일본어·중국어로 제한해 요청합니다.
  서비스가 기능을 지원해야 하며, OS 버전만으로 지원을 보장하지 않습니다.
  언어 미확인·모델 전환 실패 시 직접 언어를 고르고 다시 시도하도록 안내합니다.
- 구간별 인식 언어를 유지하고 해당 원문에서 선택한 언어로 번역합니다.
  한 문장 안의 혼합 언어, 겹쳐 말하기, 소음 속 정확도는 미검증입니다.
- 자동 화자 분리는 제공하지 않습니다. 화자 이름은 사용자가 구간별로 지정합니다.
- 녹음 중 받아쓰기는 앱의 준비된 로컬 인식 엔진을 사용하며 말하는 언어를 지정해야 합니다.
  자동 언어 감지는 지원되는 기기의 녹음 후 변환 옵션이며 실시간 자동 감지로 표시하지 않습니다.
- 앱을 벗어나거나 화면을 잠그면 녹음을 종료·저장하고 변환·재생을 중지합니다.
  녹음/변환 화면은 자동 화면 꺼짐을 방지합니다. 백그라운드 장시간 녹음은 미지원입니다.
- 한 노트 최대 60분, 보관함 최대 500개, 노트 최대 2,000개 구간·4 MiB 메타데이터입니다.
  PCM WAV는 분당 약 1.92 MB입니다. 저장 공간이 부족하면 중지합니다.
- SRT 시각은 인식 엔진의 구간 추정값을 포함하므로 자막 편집 시 원음과 확인해야 합니다.

## 데이터와 모델

음성과 노트는 앱 전용 `files/voice-notes`에 저장합니다. 방송 HTTP 서버나 진단
내보내기로 공개하지 않습니다. 사용자가 선택한 문서 위치로만 내보냅니다.
**노트 백업·가져오기 → 스크립트 백업**에서 모든 녹톡 노트·직접 수정·화자·번역과
녹음 원음을 함께 ZIP으로 저장합니다. 설정의 스크립트 백업과 같은 기능입니다.
새 기기의 **스크립트 가져오기**에서 이 ZIP을 선택하면 원음까지 복원되어 재생할 수
있습니다. 같은 노트가 이미 있으면 현재 수정본을 유지합니다. 백업 전체의 형식·해시·
음원 연결을 검사한 뒤 추가하며, 복원 도중 중지되면 같은 백업으로 재시도할 수 있습니다.

백업은 최대 압축 2GB·복원 8GB를 지원하며 기기의 여유 공간이 필요합니다. 일반 문서
내려받기(JSON/TXT/SRT 등)는 읽기·편집용입니다. 앱 이관에는 **스크립트 백업 ZIP**을
사용하세요. 기존 버전의 스크립트 백업도 가져올 수 있습니다. 녹톡 원음을 포함한 새
백업을 복원할 기기는 현재 공개 버전으로 업데이트하세요. 외부 파일 전사에 사용한 음원은
종전처럼 별도 보관하고 파일 찾기로 연결합니다. 녹음은 자동 클라우드 백업에 넣지 않습니다.

실시간 받아쓰기는 앱의 로컬 인식 엔진, 녹음 후 변환은 Android의 온디바이스 인식기,
번역은 기존 ML Kit 경로를 사용합니다.
음성노트는 API 번역과 개발자 클라우드 검토를 호출하지 않습니다. 최초 번역 모델
다운로드에는 인터넷이 필요할 수 있습니다. 모델 준비 후 추론은 기기 안에서 수행합니다.
새 ASR/화자 분리 모델을 검증 없이 번들하거나 최고 성능이라고 표시하지 않습니다.

기술 근거: [Android RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent),
[SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer).

## 후속 실기기 수용 시험

Android 13 수동 언어, Android 14 이상 자동 전환을 각각 확인합니다. 한국어→영어→일본어→중국어
녹음, 언어팩 누락, 인식 서비스 미지원, 잡음/겹침, 마이크 거부, 저장 공간 부족,
화면 잠금, 강제 종료 후 복구, 방송 중 서비스 전환, TXT/SRT/WAV 재열기를 시험합니다.
실제 화자 분리 모델은 동일 기기에서 메모리·지연·화자 오류와 재배포 조건을 확인한 뒤
별도 기능으로 검증합니다. Beta는 이 물리 환경의 품질 검증을 완료했다고 주장하지 않습니다.
