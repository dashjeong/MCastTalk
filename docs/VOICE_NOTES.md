# 음성노트 사용 안내

음성노트 메뉴에서 녹음을 시작·종료하고 목록에서 저장한 노트를 엽니다. 원음과 표시된 스크립트를 확인한 뒤 앱이 제공하는 형식으로 내려받거나 공유합니다. 방송에서 저장된 내용은 ‘방송 이력’에서 확인합니다.

녹음에는 마이크 권한과 저장 공간이 필요합니다. 음성인식과 번역에 필요한 모델·음성을 미리 준비하세요. 파일 인식 기능은 Android 버전과 설치된 인식 엔진에 따라 제공 여부가 다를 수 있습니다.

다른 화면의 음성을 재생할 때 마이크 입력에 다시 들어가지 않도록 녹음 상태를 확인합니다. 복구 안내가 나타나면 원본을 보관한 상태에서 앱의 복구 기능을 사용하세요. 삭제나 버전 변경 전에 필요한 노트와 설정을 백업합니다.

공유 전에 음성·스크립트에 포함된 개인정보를 확인하세요. [전체 사용 안내](USER_GUIDE_KO.md) · [문제 해결](TROUBLESHOOTING_KO.md)
