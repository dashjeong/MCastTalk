# 유사 서비스 비교와 0.2.43 개선

조사일: 2026-09-22 KST. 공식 기능 설명과 Google Play에 노출된 공개 후기 표본을 구분했다. 후기의 작성 시점·앱 버전·기기·사용 조건이 다르므로 전체 고객의 불만 비율이나 경쟁 제품 성능 순위를 추정하지 않는다. 정확도·지연 시간 수치는 동일 조건으로 측정하지 않아 비교 점수로 쓰지 않는다.

## 2. 진단

실제 소스에서 확인한 공백:

- 녹톡의 전사 오류를 수정할 수 없고 번역 실패 후에는 받아쓰기 전체를 다시 실행해야 했다. 화자와 수동 수정 자료가 유실될 수 있는 흐름이다.
- 보관함이 긴 전사 뒤에 위치했고 제목·문장 검색이 없었다. 문장이 많을수록 관리 조작에 도달하기 어려웠다.
- 노트 저장 후 보관함 전체 JSON을 다시 읽었다. 긴 문서 번역 중 반복할 필요가 없는 디스크 작업이다.
- 웹 청취기의 sessionStorage 예외가 QR/PIN 입장을 중단시킬 수 있었다. localStorage 예외 처리와 다르게 처리되어 있었다.
- 첫 에뮬레이터 회귀에서 3개 화면 탐색 시험이 실패했다. 중첩 가로 스크롤을 세로 스크롤로 잘못 선택하거나 화면 아래의 항목을 기다리기만 하는 시험을 수정하고 재검증한다. 통과 전까지 실제 화면 품질이 확인됐다고 표시하지 않는다.

## 3. 기획 기준

화면은 목적 → 준비 조건 → 주요 행동 → 저장된 결과 순으로 구성한다. 네 서비스 이름은 녹톡·라이브톡·통역톡·스크립톡을 유지한다. 기술 트렌드 중 기기 내 처리, 필요한 모델만 준비, 사용자 수정, 중단 후 복구, 접근 가능한 레이아웃을 우선 적용한다.

[Google ML Kit 공식 문서](https://developers.google.com/ml-kit/language/translation)는 기기 내 번역과 언어별 품질 한계를 설명한다. 새 대형 모델을 추가하는 것만으로 정확도나 지연 개선을 주장하지 않는다. [Android 큰 글씨 지침](https://developer.android.com/about/versions/14/features#non-linear-font-scaling)에 따라 200% 글씨에서도 조작을 확인한다.

무료/유료 가격 정책이나 새로운 과금·클라우드 전송은 추가하지 않는다. 유료 수준의 품질 목표는 한도·실패 안내, 기록 보존, 재시도, 수정, 접근성, 개인 자료 보호의 수용 기준으로 사용한다. 무불만·무오류를 보증하지 않는다.

| 녹음 한도 | 최대 60분 사전 안내와 남은 시간 | 회의 중 한도를 뒤늦게 알게 되는 문제 완화 |
| 성능 | 저장한 노트의 요약만 메모리 목록에 반영, 녹음 시간 표시 약 250ms 간격 | 반복 전체 파일 읽기와 불필요한 UI 갱신 제거. 실기기 배터리 개선률은 미측정 |
| 청취·보안 | 저장소 차단 브라우저에서 인증 정보를 페이지 메모리로 제한 | QR/PIN 입장 유지. URL fragment 제거·Authorization 전송·인증 만료 처리 유지 |

백업 규칙은 [Android 공식 백업 문서](https://developer.android.com/identity/data/autobackup)의 저장소 도메인 구분을 기준으로 보강하고, 최종 APK에 담긴 리소스와 백업 허용 플래그를 Android 시험에서 확인한다. 실제 제조사 기기 이전 동작은 원 장비 점검 대상이다.

## 5. 시험검증과 공개 기준

앞선 10회 결과는 `SIMULATION_REPORT.md`에 별도 보존한다. 이 문서의 변경은 후속 검증이며 이전 결과에 소급해 포함하지 않는다.

- 단위시험: 문장 수정 후 낡은 번역 제거, 직접 수정 보호, 검색 인덱스, 구간 순서, 네트워크 실패 후 재시도, 실제 coroutine 취소 후 저장, 저장 공간 오류, 2,000개 구간 체크포인트 횟수.
- 브라우저 모의시험: 저장소 get/set/remove 거부, QR/PIN 인증, 기존 재연결·인증 범위·XSS 방어·백오프 회귀.
- Android: 실제 Repository 재개방, ViewModel 편집/이름 변경/번역 재개, 다른 노트 삭제 시 현재 노트 유지, 구간 재생, 200% 글씨와 낮은 화면, 전체 관련 회귀.
- 공개용 최적화 Alpha APK의 빌드·lint·원천 자료 해시·패키지·16KB 정렬·자산 검증. CI의 동일 APK에 임시 QA 서명을 입혀 실행한다. 원 개발 장비의 최종 서명은 별도다.

실기기가 없어 실제 마이크·블루투스·혼잡한 현장 Wi-Fi·ARM64 모델·발열·배터리·언어별 인식/번역 정확도는 통과로 처리하지 않는다. S23 firstPCM p95 ≤ 2,000ms 등 기존 공개 수용 기준의 실제 측정은 원 장비에서 남은 필수 점검이다. 최종 결과·APK 해시는 비공개 인계 문서에서 확인한다.
