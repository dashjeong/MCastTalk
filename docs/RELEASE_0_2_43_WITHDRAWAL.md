# 0.2.43 공개 철회 및 보수 전환

2026-09-23, 다수 기능 실패와 초기 메뉴 구성 문제 보고에 따라 0.2.43 공개 배포를 철회했다.
현재 공개본은 **0.2.42-alpha**다. 이는 0.2.42의 모든 기능을 새로 보증한다는 뜻이 아니다.

## 즉시 조치

- 0.2.43 릴리스를 초안으로 전환하고 공개 APK 다운로드를 중단했다.
- 공개 0.2.43 태그를 삭제하고, 원래 소스는 `codex/maintenance-0.2.43` 브랜치에 보존했다.
- `main`의 제품 코드·리소스·빌드 설정은 0.2.42 태그와 동일하게 복구했다.
  이 문서·README·철회 상태 안내 외에 0.2.42 제품을 변경하지 않는다.
- 0.2.42의 기존 서명 APK를 그대로 제공한다. 파일을 다시 빌드하거나 바꿔치기하지 않는다.

## 설치된 0.2.43과 데이터

GitHub의 공개 철회는 이미 설치된 앱을 원격으로 낮추거나 종료하지 않는다.
0.2.42는 versionCode 48, 0.2.43은 49여서 Android가 단순 덮어 설치를 거부할 수 있다.
삭제 후 재설치는 앱 내부 자료를 잃을 수 있으므로 권장하지 않는다.
0.2.43의 신규 녹음 노트와 교차 교정 자료는 이전 버전의 호환 복원을 검증하지 않았다.
원본 자료를 보존하고, 백업·복구 호환성을 확인하는 별도 이관 경로를 검토한다.

## 보수 범위와 재공개 조건

1. **기능 재현표:** 실제 첫 실행부터 입력 권한, 모델 준비/재사용, 음성 입력, 원문,
   번역, TTS, 로컬/방송 청취, 중지·재시작까지 사용자 경로로 확인한다.
   테스트 개수로 이 전체 경로의 성공을 대신하지 않는다.
2. **초기 화면:** 긴 소개문과 서비스별로 갈라지는 화면 대신 공통 인앱 구조를 유지한다.
   명확한 기능명과 짧은 설명을 갖춘 카드/박스 메뉴, 공통 운영·시험·설정 접근,
   일관된 뒤로가기를 설계한다. 메뉴 진입이 저장 설정을 바꾸지 않아야 한다.
3. **전체 기능:** 기기 음원·앱 검색, 실시간 통번역/HUD, 녹음 노트, 파일 일괄 변환·재작업,
   재생 동기화, 보관함·백업/복원, 실험실 승인/보류/취소를 각각 정상·실패·복구로 점검한다.
4. **자료 보존:** 기존 사용자 수정, 언어·단독기기 선택, 받은 모델, 스크립트와 음원을 유지한다.
5. **검증 분리:** 코드에서 확인된 결함, 자동시험 재현, 실기기 재현, 미검증 가설을 분리한다.
   녹음·인식·번역·청취와 화면 이동을 실제 사용자 진입점에서 검증한다.
6. **출시 차단:** 보수 브랜치에서는 APK를 공개 릴리스하지 않는다. 기능 재현과 수정·회귀시험,
   실제 진입 화면 확인 및 데이터 보존을 기록하고 새 공개 승인을 받아야 재공개한다.

이전 JVM/에뮬레이터 시험이 실행된 사실은 남지만, 실제 서비스가 사용 가능하다는
출시 판단에는 부족했다. 기능 문제를 해결했다거나 상용 수준이라고 현재 주장하지 않는다.
이번 철회는 새 APK 개발·검증 완료가 아니라 배포 경로와 소스의 긴급 복구다.
