# 0.2.45-beta 공개 후 재검증 — 2026-09-24

Antigravity가 공개 APK의 실제 에뮬레이터 시험을 실행하고, Codex가 실행 기록·APK 해시·판정 근거를 교차 확인했다. **마이크 전사 실패는 미해결이며, 제품 수정이 없어 C 버전은 발행하지 않았다.** 앱과 가상 입력 환경 중 어느 쪽이 원인인지 확정하지 못했다.

## 대상과 신규 실행

- 공개 APK SHA-256: `64e994a7d0e1c128ae4c131f05f609cbad208f6757119636b97edc289eaa3239`
- 제품 소스: `2749c67a931200ea795981308bcda1e96d7fc853`와 동일. 이 보고서는 문서 변경이다.
- Android 15 ARM64 AOSP / emulator 37.1.11. 실기기 시험이 아니다.
- 호스트 마이크는 차단하고 공개 FLEURS fixture만 사용했다. 16 kHz, mono PCM S16LE, 7.02초, 224,640 bytes.
- 시험: `VoiceNoteMicrophoneJourneyDeviceTest.microphoneRecordingShowsAndSavesActualSpeechBeforeStop`
- 신규 실행 식별자: `beta045-loop-paced-reference/20260924T064636Z`, 06:46:36–06:48:13 UTC.
- 같은 fixture를 최대 10회 페이싱 주입했다. gRPC 전송 완료는 Android의 정상 수신을 증명하지 않는다.
- 실행 전후 설치된 앱과 시험 APK 해시가 각각 일치했다.

## 단위 시험 및 검토 범위

Antigravity가 JDK 17에서 `:core:translation:test :app:testAlphaUnitTest --offline --no-daemon --max-workers=1`을 실행했다. `BUILD SUCCESSFUL in 13s`, 147 tasks 중 2 executed / 145 up-to-date였다. 해당 시험 작업은 **UP-TO-DATE**로 기존 결과를 재사용했으며, 이를 신규 시험 사례 실행으로 집계하지 않는다.

오디오 수신·음성노트 전사·문장 확정 코드도 검토했다. 재현과 수정 후 검증까지 완료된 신규 제품 결함은 확보하지 못했다. 이는 결함 부재나 잔여 지연 해결을 증명하지 않는다. 음성노트 인식 큐 포화 시 전사가 중단되는 경로는 코드상 존재하지만, 이번 마이크 실패의 원인으로 입증되지 않았다.

이전에 통과한 최종 APK 기능 경로 9건과 공개 음원 시험은 [기존 보고서](TEST_REPORT.md)에 남아 있다. 이번 마이크 시험 통과로 바꾸어 해석해서는 안 된다. 미해결 번역 오류와 31.385초 문장 확정 간격, 실기기·8시간 검증 한계 역시 유지된다.

## 배포 판단

0.2.45-beta는 알려진 실패를 명시한 시험용 공개본으로 유지한다. 제품 코드·APK 변경 없이 버전만 C로 올리지 않는다. 새 가상기기 대조 시험은 약 7.37 GB를 요구하지만 가용 공간이 약 3.8 GiB여서 실행하지 못했다. 사용자 파일과 기존 AVD를 삭제하지 않았다. 원인 분리와 수정 검증이 아직 남아 있다.
