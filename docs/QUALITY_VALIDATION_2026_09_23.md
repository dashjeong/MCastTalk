**판정은 공개 재배포 보류입니다.** 실제 음원을 입력해 문장 분리와 마지막 전사 누락을 재현했고, 관련 코드를 수정해 같은 음원으로 재시험했습니다. 마지막 구문 전달은 개선됐지만, 지정 영상에서 선별한 기존 번역 오류 5건은 수정 후에도 그대로 남았습니다. 앱 전체나 통번역 품질이 정상화됐다는 완료 보고가 아닙니다.

공개 버전은 0.2.42를 유지합니다. 이는 0.2.43 철회 상태의 유지이며, 0.2.42의 번역 품질을 보증하는 의미가 아닙니다. 보수 APK는 검증용으로만 사용했고 공개 배포하지 않았습니다.

## 실제 시험 범위

macOS ARM64의 전용 Android 15 API 35 AOSP ARM64 에뮬레이터에서 시험했습니다. 공개 원음에서 추출한 16 kHz 모노 PCM S16LE를 실제 앱의 Moonshine 인식, 의미 구간화, Google ML Kit 로컬 번역 경로에 투입했습니다. 모의 인식문만 넣은 단위시험과 실제 음원 시험은 구분했습니다.

공개 장문 코퍼스 시험은 별도 실행 원장에 파일별 출처, 원본 구간, 길이, PCM 해시와 실제 결과를 기록했습니다. 동일 음원의 짧은 부분을 반복 연결해 2분으로 늘리지 않았습니다. 7개 언어 각 30건이라는 전체 요청은 아직 완료되지 않았습니다.

## 확인한 원인과 반영한 수정

**문장 경계 선택.** 여러 문장이 한 인식 결과에 들어오면 마지막 경계를 선택하거나, 무음을 이유로 남은 내용을 한꺼번에 확정하는 경로가 있었습니다. 먼저 확인된 완성 문장부터 순서대로 처리하고, 이미 관찰한 안정 가설을 보존해 나머지 문장을 이어서 확정하도록 수정했습니다. 미완성 주어·조건·연결구·부정 표현을 시간 경과만으로 번역에 넘기지 않도록 보완했습니다.

**한국어와 영어의 완결성 판정.** 한국어 회고형·과거형·약속형 종결을 보완했습니다. 숫자 뒤의 ‘네’를 긍정 대답으로 간주해 다음 단위와 분리하던 사례를 회귀시험에 추가했습니다. 영어 대명사가 문장 끝에 있다는 이유만으로 완성된 목적어·의문문까지 대기시키던 문제도 수정했습니다. 이 규칙들은 모든 문법과 의미를 이해하는 파서가 아닙니다.

**마지막 음성 회수.** 유한 음원이 끝나도 인식 흐름이 계속 대기하고, 기존 중지 경로는 최종 전사 전에 listener를 제거할 수 있었습니다. 정상 EOF와 취소를 분리하고, 네이티브 최종 전사와 결과 전달, 자원 정리, 종료 확인 순서로 처리했습니다. 종료 확인 시간 초과와 실패를 성공으로 바꾸지 않습니다.

**종료 경합과 중복 방지.** 공급자가 PCM을 버퍼에 다 넣은 시점과 실제 인식기가 끝까지 소비한 시점을 구분했습니다. EOF 이후 자동 재시작이 최종 전사를 취소하지 않도록 했으며, 완료한 네이티브 발화 ID의 늦은 callback은 다시 새로운 문장으로 만들지 않습니다. 저장 상한은 명시적으로 처리하고 무한 보관하지 않습니다.

문장 수가 달라졌다는 사실 자체를 품질 향상으로 계산하지 않았습니다. 두 번째 영상에서 소개와 인사가 나뉜 사례는 확인했지만 긴 문장 묶음과 인식 반복도 남았습니다. 이전에 남았던 마지막 구문이 전달된 것은 EOF 개선의 증거입니다. 해당 원본 구간이 종속절에서 끝났다면 EOF 회수만으로 의미가 완성되는 것은 아닙니다.

인식 결과는 같은 PCM에서도 달라질 수 있습니다. 따라서 모든 원문 차이를 코드 수정의 효과로 단정하지 않았습니다. 문장 끊음 오류율은 독립적으로 검증한 경계 정답이 없어 산출하지 않았고, 구체적인 오류 사례와 실행상 누락을 분리해 기록했습니다.

한국어 첫 5건에서 따로 지정한 경계 3건은 재시험에서 개선을 관찰했습니다. ko02는 완성된 회고문과 다음 예시를 나눴고, ko03은 숫자와 단위를 같은 구문에 유지했으며, ko04는 중간 긍정어 때문에 주어와 서술어를 분리하던 부분을 함께 전달했습니다. 이 3건의 경계 검사를 전체 원음 정확도나 번역 품질 통과로 확대하지 않았습니다.

## 현재 assistant 번역과의 비교

비교 번역은 현재 OpenAI Codex assistant가 실제 인식문과 문맥을 검토해 생성했습니다. 별도 ChatGPT API를 호출하거나 ChatGPT 서비스의 속도를 측정한 시험은 아닙니다. 다음은 원음의 정답 전사에 대한 판정이 아니라, 실제 인식문에서 번역문으로 넘어가며 발생한 의미 변화에 대한 AI 검토입니다.

**첫 영상의 숫자.** 인식문 ‘칠십 삼 년’은 실제 영어에서 ‘seven years’로 바뀌었습니다. 비교 번역은 ‘seventy-three years’입니다. 수정 후에도 같은 인식문과 오역이 남았습니다.

**첫 영상의 문맥.** 군사·한반도 문맥의 ‘정전’과 ‘정전체제’가 각각 ‘power outage’, ‘electrostatic system’으로 번역됐습니다. 문맥을 반영한 비교 표현은 ‘armistice’, ‘armistice system’입니다. 로컬 ML Kit 경로는 별도 이전 문맥 입력을 지원하지 않으며, 문맥 문자열을 보관하는 것만으로 모델에 반영되지는 않습니다.

**두 번째 영상의 사람과 시간.** 인식문 ‘몇 분’은 뒤의 높임말과 서 있다는 문맥에서 사람을 가리키지만, 영어는 ‘A few minutes’로 바꾸고 행위자도 바꿨습니다. 비교 표현은 ‘A few people had been standing’입니다.

**두 번째 영상의 기간.** 인식문 ‘오십육 년째’와 일상적으로 방송한다는 정보가 실제 영어에서 빠졌습니다. 비교 표현에는 ‘in my fifty-sixth year of broadcasting’이 포함됩니다. 원음에서 실제 발화된 숫자를 청취로 확인한 결과는 아닙니다.

이 5건은 문제를 확인하기 위해 선별한 사례이며 수정 후 해결된 사례는 0건입니다. 이를 전체 제품 오류율로 환산하지 않았습니다. 별도 한국어 코퍼스의 목적표집 8문장에서는 AI 검토로 중대 의미 변화 5건을 확인했지만, 역시 전체 음원이나 사용자 환경의 대표 비율이 아닙니다.

## 실행 결과와 남은 검증

한국어 공개 장문 30건을 5개 시험기에서 5건씩 6개 묶음으로 실제 실행했습니다. 각 음원은 2분 이상이며 합계 63분 15.6초입니다. 30건 모두 입력 전체 바이트와 PCM 해시가 일치했습니다. 23건은 실행 완료, 7건은 인식 결과가 없는 `NO_SEMANTIC_FINALS` 실패였습니다. 305개 확정 구문에 대한 번역 요청 305건이 완료됐고 종료 후 미회수 꼬리는 0개였습니다. 이 결과는 인식 정확도나 번역 의미 보존의 통과 판정이 아닙니다.

무출력 7건은 ko12, ko13, ko21, ko22, ko25, ko28, ko30입니다. 모두 공급자 인식 콜백 0건이며 정상 입력 EOF가 확인됐습니다. 그중 ko12와 ko13은 같은 PCM을 앱의 의미 조립과 자동 재시작을 거치지 않는 Moonshine 엔진에 직접 입력해도 `NO_NATIVE_FINALS`로 실패했습니다. 이 비교에서도 전체 바이트와 해시는 일치했고 정상 종료했지만 부분·최종 전사는 모두 0건입니다. 따라서 이 두 건을 의미 분할이나 자동 재시작이 일으킨 실패로 단정할 수 없습니다. 모델·VAD·음원 조건의 정확한 원인은 미확정입니다. 단순 무음 파일은 아니지만, 독립 청취를 하지 않아 음악·합성음 여부도 확정하지 않았습니다.

SDK가 내부 정수 반환값을 버리는 부분까지 확인하기 위해 네이티브 API 직접 진단도 실행했습니다. 동일한 한국어 모델 파일 해시와 옵션에서 ko01은 6,386개 PCM 입력 호출이 모두 성공 코드였고 최종 전사 29개를 관찰했습니다. ko12는 6,332개 호출이 모두 성공 코드였으나 네이티브가 반환한 전사 행 자체가 0개였습니다. 두 경우 모두 전체 입력 해시와 EOF가 일치했습니다. 이번 ko12 무출력은 앱의 빈 문자열 필터 뒤에서 사라진 것이 아니며, 검사한 JNI 반환 코드에도 오류가 없었습니다. 이 관찰만으로 VAD 또는 모델을 단일 원인으로 확정하지 않았습니다.

가상 마이크 시험은 호스트의 실제 마이크를 비활성화한 뒤 공개 7.02초 FLEURS 음원만 사용했습니다. 증빙의 가상 마이크 receipt에서 호스트 실행 실패를 parser에 전달해 발생한 ‘adb exited unsuccessfully’ 문구는 별도로 관찰한 adb 자체 실패를 뜻하지 않습니다. 원본 기록과 이 해석상 한계를 함께 보존했습니다.

## 후속 품질 개선과 공개 조건

종료·큐·문장 분리의 구현 수정은 실제 재시험 결과와 함께 보존합니다. 그러나 숫자, 다의어, 고유명사와 원문 인식의 의미 손상을 개선하지 않은 채 공개 품질 통과로 바꾸지 않습니다. 특정 영상에 맞춘 정답 치환이나 시험 조건 완화로 오류를 숨기지 않았습니다.

다음 품질 개선은 문맥을 받는 번역 경로와 더 정확한 인식 경로를 동일 음원으로 비교하고, 숫자·부정·조건·주체·동작·목적어를 검토하는 단계입니다. 현재 로컬 경로의 한계를 문장 분리 규칙만으로 해결했다고 주장할 수 없습니다. 모델이나 경로 변경은 실제 앱에서 정확도·속도·메모리·실패 복구를 재검증한 뒤 채택해야 합니다. 지정 영상 5건과 별도 코퍼스 5건을 합친 선별 중대 번역 오류 10건은 이번 수정 후에도 남아 있습니다.

공개 판단을 바꾸려면 먼저 무출력 7건의 원인을 밝혀 같은 입력으로 재시험하고, 원음을 독립 청취해 정답 전사와 의미 경계를 확정해야 합니다. 그 뒤 기존 번역 오류 10건과 새로운 비교 표본에서 인식·경계·번역 각각의 오류를 측정해야 합니다. 다른 6개 언어의 엔진 지원과 실제 음원 시험도 현재 미완료이며 한국어 결과로 대체할 수 없습니다.
