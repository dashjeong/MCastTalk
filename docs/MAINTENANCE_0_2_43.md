# 0.2.43 보수 전환 · 기능과 서비스 재검토

2026-09-23. 상태: **공개 철회, 수정·재검증 미완료, 재배포 금지**.
공개 `main`은 0.2.42 제품 코드로 복구했다. 이 브랜치는 철회 원인을 조사하고 보수하기 위한
소스이며, 아래 계획과 정적 검토는 새로운 기능 시험 통과를 뜻하지 않는다.

## 코드에서 확인된 사항

검토 기준은 철회한 `7e5d915207521ff6b561549ec0ed707f7166e8cc`이다.

- `MainActivity.kt:418–424`: 원음/다국어 홈 메뉴를 열 때 STANDALONE을 NETWORK로 저장해
  덮어쓴다. 단독기기 선택은 명시적으로 바꿀 때만 변경해야 한다.
- `MainActivity.kt:417–440,512–543`: 홈·녹음·파일 경로가 공통 Scaffold 전에 반환하여
  운영/시험/설정 접근이 서비스마다 다르다. 단일 인앱 탐색 구조로 복구해야 한다.
- `MainActivity.kt:464,826–835,874`: 라이브톡에서 비서의 언어 설정 목적지와 실제 노출 화면이
  일치하지 않는다. 목적지·탭·설정 카테고리를 하나의 탐색 상태로 관리해야 한다.
- `VoiceNoteViewModel.kt:81–147`: 녹음은 AudioRecord→WAV 저장·시간 표시만 수행한다.
  `:172–188`의 전사는 별도 버튼 이후 실행된다. 따라서 **녹음 중 기본 실시간 노팅은 빠져 있다**.
- `FileSpeechTranscriber.kt:69–78`: 후처리 전사는 Android 13+의 플랫폼 온디바이스 인식 서비스에
  의존한다. API 버전만으로 언어팩·서비스 지원을 보장할 수 없으며 녹음 전 실제 준비 진단이 필요하다.
- `FileSpeechTranscriber.kt:102–165`, `VoiceNoteViewModel.kt:178–187`: 전사 완료 이전의 구간은
  영속 저장되지 않아 중단 시 재처리한다. 확정 구간별 저장·재개가 필요하다.
- `VoiceNoteScreen.kt:111–114`, `DataTransferPanel.kt:148`: 노트로 돌아가는 버튼이
  ‘설정으로 돌아가기’라고 표시된다. 실제 목적지에 맞는 일관된 뒤로가기가 필요하다.

준비 실패, 모델 불가, 권한 거부, 출력 언어 0개, 방송 중 시험 비활성 등은 각각 다른 상태다.
아직 이 중 하나를 사용자 송출 실패의 원인이라고 단정하지 않는다.

## 음성노트 기본 흐름 재정의

1. 시작 전 마이크 권한, 실제 STT 서비스·원어 지원, 저장 공간을 확인한다. ‘녹음 가능’과
   ‘실시간 전사 준비됨’을 구분한다. 미지원이라면 녹음만 하는 대체 동작을 명확히 선택하게 한다.
2. **녹음 시작과 동시에 전사 영역을 보여준다.** 하나의 마이크 캡처를 원음 저장과 스트리밍
   인식에 분기하고, 기존 음성 엔진의 단일 마이크 소유권을 보존한다. 두 독립 녹음기로 경합시키지 않는다.
3. 변경 중인 가설은 임시 문장으로, 확정 문장은 시간 구간과 함께 누적 표시·체크포인트 저장한다.
   번역은 선택 사항으로 확정 원문 아래에 표시하고, 번역 지연이 녹음/원문 표시를 막지 않게 한다.
4. 종료·인식기 재연결·앱 전환에서 최종 문장의 중복/유실을 방지한다. 인식 실패 시 저장된 원음과
   확정 문장을 유지하고 실패 구간 재전사를 제공한다. 재녹음을 유일한 복구 방법으로 두지 않는다.
5. 완료 후 원음·전사·선택 번역·사용자 수정이 같은 노트로 열린다. 구간 재생, 수정, 백업·복원까지
   실제 홈에서 시작한 사용자 여정으로 검증한다. 잠금·백그라운드 지원은 실제 검증 후 명시한다.

## 화면 구성 재검토안

- 공통 앱 틀 안에 **운영 · 시험 · 설정**을 유지한다. 서비스마다 다른 앱처럼 탭을 없애지 않는다.
- 운영 화면은 **실시간 통역 / 원음 방송 / 음성 노트 / 파일 변환·재생** 카드로 구성한다.
  각 카드는 기능명·한 줄 설명 중심이며, 일반 폭 2열/좁은 폭·큰 글꼴 1열로 적응한다.
- 녹톡·라이브톡 등의 별칭은 보조로만 사용한다. 긴 소개문·모델 설명은 첫 화면에서 줄이고,
  작업에 필요한 설정과 상태를 해당 단계에 둔다.
- 메뉴 이동은 저장 설정을 바꾸거나 작업을 시작하지 않는다. 진행 작업 복귀·중지 버튼은
  항상 찾을 수 있게 하고 입력과 방송 제어는 독립적으로 유지한다.
- 원문·번역·노트가 중심이다. 로그성 수치와 경로는 개발자 표시에서만 제공한다.
- 핵심 음성 기능이 미동작하는 상태에서 외형을 다듬은 것만으로 보수 완료라 하지 않는다.

## 직전 검증을 정정하는 기준

직전 UI 시험은 이미 전사된 합성 노트를 넣고 화면을 직접 렌더링했다. 홈에서 권한→녹음→실제
전사→번역을 완료한 시험이 아니다. 업데이트 시험은 저장값 읽기까지만 확인하여, 이후 메뉴
진입으로 단독기기 설정이 바뀌는 경로를 놓쳤다. 방송 시험음과 직접 TTS 호출도 실제 원어
입력부터 다국어 송출까지의 성공을 대신하지 않는다.

수정 후에는 위 사용자 여정의 실제 출력과 실패 복구를 증거로 남긴다. 사용자 음성·문장·키를
진단 로그나 공개 보고서에 담지 않는다. 실기기 청취·시간 안정성은 수행하지 않았다면 그대로
미검증으로 표시한다. **이번에는 기능 확인과 사용자 검토 이전에 자동으로 재공개하지 않는다.**
