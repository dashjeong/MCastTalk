# 실험실 · 문맥을 반영하는 교차 검증 학습

## 진단과 설계

직역이 문맥·상황과 어긋나도 숫자·길이 검사만으로는 발견하기 어렵다. 두 제공자의 문장 검토와 독립 재검토를 추가하되, 유창함이나 답변 일치를 의미 정확도의 보증으로 취급하지 않는다. 모델 가중치 학습이 아니라 사용자 승인 교정의 조건부 재사용이다.

1. 실험실에서 OpenAI·Google 키를 각각 기기의 암호화 저장소에 등록한다. 주 검토 모델과 상대 검토 모델 ID, 방송 상황을 지정한다.
2. 온라인 허용과 별도의 두 제공자 전송 허용을 켠다. 기본값은 꺼짐이다. 설정 가져오기는 전송·학습 동의를 복원하지 않는다.
3. 숫자·언어·번역 변동·문맥 표본 또는 직접 요청한 문장을 선별한다. 그룹당 최대 3회 API 요청, 분당 최대 2개 그룹으로 제한한다. 실시간 낭독은 네트워크 검토를 기다리지 않는다.
4. 두 제공자에 원문·앱 번역·직전 문맥 최대 1,000자·상황 최대 300자를 보내 각각 독립 교정안을 받는다. 음원·전체 방송·진단 로그는 보내지 않는다.
5. 로컬 내용 검사 후 상대 제공자가 주 후보를 다시 검토한다. 의미, 누락, 부정·조건, 의도, 숫자·고유명사·단위, 기존 교정 대비 퇴보를 검사하도록 요청한다. 불일치·응답 없음·검사 실패는 보류한다.
6. 학습 대기목록에 앱 번역, 두 후보, 모델 ID, 상황·문맥, 검증 결과, 유사 교정 연결 정보를 보관한다. 적용은 사용자 승인 뒤에만 일어난다.
7. 원문·언어·문체·직전 문맥·상황의 정규화된 키가 모두 일치할 때만 승인 교정을 재사용한다. 유사도는 검토 후보 검색에만 쓰며, 비슷한 다른 문장에 교정을 자동 전파하지 않는다.
8. 승인 직전에 기존 교차 교정과 일반 문장 교정의 버전을 다시 비교한다. 검토 도중 변경된 기록은 덮어쓰지 않고 재진단을 요구한다. 최신 교정의 취소는 이전 버전을 복원한다. 오래된 승인 화면은 새 버전을 취소할 수 없다.
9. 불일치·보정 근거 없음은 같은 검토 조건에서 24시간 재전송하지 않는다. 모델·문맥·기존 교정 버전이 달라지면 새 검증으로 취급한다. 전송 대기열을 무한히 쌓지 않으며 바쁜 동안 생략한 수와 직접 진단 재시도 안내를 표시한다.

## 보관과 복원

최근 비교 기록은 200건, 승인 교차 교정은 최대 500건이다. 승인 교정은 비교 기록 정리와 별도로 보관한다. 전체 기록 내보내기와 사전 백업은 승인 교정의 근거를 포함한다. 가져온 자료는 적용 권한 없는 비교 기록으로 처리하므로 새 기기에서 재검증해야 한다. 키·토큰·클라우드 전송 동의는 백업하지 않는다.

취소는 보관된 직전 버전까지만 복원한다. 더 오래된 복원 정보가 없더라도 '이 문맥 교정 사용 해제'로 현재 교정을 끌 수 있다. 이 조작은 이전 교정을 복원하지 않고, 직접 저장한 문장 사전은 유지한다. 이후 비교 기록 정리로 남은 평가 내용을 지울 수 있다. 오래된 화면에서 최신 교정을 해제하는 요청은 거부한다.

## 품질 기준과 한계

모의 제공자 응답, 숫자 오류, 서로 다른 교정, 응답 누락, 취소, 설정 변경, 문맥 격리, SQLite 저장·승인·기존 버전 충돌·취소·이관 권한을 시험한다. 실제 API 호출과 실제 Android 실행은 별도 증거가 있어야 통과로 기록한다. 현재 API 키와 물리 기기가 없는 환경에서 실서버 품질이나 현장 번역 정확도를 검증했다고 표시하지 않는다.
