# MCastTalk 0.2.44 Alpha

철회된 0.2.43을 구분하는 보수판이다. 현재까지의 수정 결과를 공개해 달라는 사용자의 요청에
따른 Alpha 공개이며, 모든 언어·기기·연속 운영 품질의 통과 선언은 아니다.

## 반영한 개선

- 음성 입력의 끝부분 처리와 전사 보관·재진입 관련 보수 작업을 포함한다.
- 한국어 높임 주어의 사람 수를 시간으로 잘못 해석하는 경우를 제한된 문법 근거로 보완한다.
  화면과 보관 원문을 보존하고 ML Kit의 번역 입력 복사에서만 처리한다.
- 같은 숫자의 `73`/`Seventy-three` 표기 차이 때문에 올바른 보완을 버리던 문제를 수정한다.
  값 변경·누락·순서·중복 보호와 미지원 숫자 표현의 보수적 거부는 유지한다.
- 공개 사전의 `정전=power outage`가 군사 문맥에 강제되는 경우를 줄인다.
  운영자가 편집한 사전 항목의 우선권은 유지한다.
- 선택적 보완을 켰을 때 공정 큐와 실제 추론이 기존 800ms 제한으로 취소되지 않도록 한다.
  AUTO도 문맥 검토를 수행하며 추가 대기가 가능함을 설정 화면에 표시한다.
- 프랑스어·독일어 ML Kit 번역 입력 모델 준비를 보완한다. 음성인식 지원 확장을 뜻하지 않는다.

## 확인 범위

실제 에뮬레이터 실행, 서명·정렬·설치본 해시, 단위 회귀·lint·라이선스 검사 결과는
[검증 보고서](MISTRANSLATION_REVIEW_2026_09_24.md)와 [시험 이력](TEST_REPORT.md)에 기록한다.
원문·실제 출력 대조와 Antigravity의 독립 텍스트 검토를 병행했다.

공개 APK의 실제 사용자 경로 4건(음성 송출, 시험 재실행, 파일 변환/재생, 사용자 사전 우선권)은
모두 통과했다. 같은 설치본에서 문맥·공정 큐 26건, ML Kit 7원어 21건, Gemma 지원 5원어 15건을
실제 실행했다. 문맥 의미 검사는 알려진 관계 오류 때문에 FAIL이며, 실행 완료와 품질 통과를 구분한다.
모든 필수 로컬 빌드 게이트·서명·16KiB 정렬·설치 전후 해시를 확인했다.

공개 APK SHA-256: `4c344a8375a7ebb0f5724eac79b18b3b8c3a808c21a3e97ade8de2092c0efa0c`

## 알려진 제한

- `4년째이지만 만 3년 경과`를 잘못 번역하는 관계 오류가 남는다.
- ML Kit 다국어 작성 예문에서 입장료 용어와 도착 시점/기한을 바꾸는 사례가 남는다.
  Gemma도 모든 원문을 정확히 번역하는 것은 아니다.
- 현재 앱의 Gemma 공급자는 프랑스어·독일어 입력을 지원하지 않는다.
- 실제 다국어 음성인식 코퍼스 전체, 8시간 연속 운영, 물리 단말 지연·음질은 입증하지 않았다.
  에뮬레이터 가상 마이크의 엄격한 파형 타이밍 실패 이력도 합격으로 변경하지 않았다.
- 의미 보완이 추론 시간을 추가한다. 언어를 동시에 많이 사용한 실제 지속 처리량은 별도 확인이 필요하다.

Android 11 이상 ARM64용이며 기존 공개 앱과 같은 배포자 서명, `versionCode 50`을 사용한다.
0.2.42 공개본과 철회한 0.2.43 기록은 그대로 보존한다.
