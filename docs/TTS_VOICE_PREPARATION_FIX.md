# 기기 음성팩 준비·복구 안내 — 0.2.46-beta-c

## 확인한 문제

사용자 화면은 중국어 간체에서 Google 우선을 선택한 뒤 ‘통역 음성 · 확인 필요’를 표시했습니다. 상세에는 정상적인 ‘설치된 오프라인 음성 선택’ 안내가 Moonshine 오류처럼 포함됐고, 실제 Android 음성을 찾지 못한 원인은 문장 뒤에서 잘렸습니다. 이는 다운로드 진행 표시가 아니라 준비 실패 표시였습니다. 사진만으로 해당 기기에 엔진이 없는지, 언어팩이 없는지, 엔진이 다른 오류를 냈는지는 확정할 수 없습니다.

앱은 설치된 Google·Samsung 오프라인 음성을 사용할 수 있지만, 기존 언어 선택 화면은 음성팩 설치 동작과 연결되지 않았습니다. 별도 도구 메뉴의 설치 화면에서 돌아와도 TTS 상태를 다시 확인하지 않았습니다.

## 사용 흐름

1. 언어별 상태를 ‘준비 필요 / 확인 중 / 준비 실패 / 준비됨’으로 구분합니다. 준비 전 상태를 빨간 오류로 표시하지 않습니다.
2. 해당 언어의 **음성팩 설치 · 복구**를 누르면 실제 오류 이유와 설치 동작을 볼 수 있습니다.
3. 설치된 Google·Samsung 엔진의 공식 음성 데이터 설치 화면을 엽니다. 설치 화면을 제공하지 않으면 Android TTS 설정으로 연결합니다. Google 엔진이 없으면 공식 Play 스토어 설치 페이지를 제공합니다.
4. 설치 또는 취소 후 앱으로 돌아오면 음성 사용 가능 여부를 다시 확인합니다. 설치 화면을 열거나 닫았다는 이유만으로 ‘준비됨’으로 바꾸지 않습니다. 방송·입력·시험·다른 준비가 진행 중이면 종료 후 다시 확인하도록 안내합니다.
5. 설치한 음성팩과 Moonshine 모델 파일을 보존합니다. 이 재확인은 번역 모델·음성인식 모델을 다시 내려받는 작업이 아닙니다.

Google·Samsung 언어팩을 앱에서 임의 서버로부터 내려받지 않습니다. 설치·동의·다운로드는 해당 엔진이 관리합니다. 첫 설치에는 인터넷이 필요할 수 있고, 엔진이 지원하지 않는 언어는 다른 지원 엔진이 필요합니다.

## 검증 범위

최종 실행 명령·시험 결과·APK 해시는 [시험 보고서](TEST_REPORT.md)에 기록합니다. Android 에뮬레이터의 설치 화면 연결과 결과 복귀 검증은 실제 Samsung/Google 언어팩 다운로드 성공이나 물리 Galaxy 음질 검증을 뜻하지 않습니다. 사용자 사진과 개인정보는 공개 자료에 포함하지 않습니다.

공식 API: [ACTION_INSTALL_TTS_DATA·KEY_FEATURE_NOT_INSTALLED](https://developer.android.com/reference/android/speech/tts/TextToSpeech.Engine), [TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech).
