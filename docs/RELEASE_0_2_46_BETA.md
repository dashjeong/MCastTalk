# 0.2.46-beta — E2B 유지 및 E4B-IT 선택

최종 패키지와 전용 에뮬레이터 시험 결과를 검수한 베타 변경 내역입니다. 안정판 인증이 아닙니다.

## 변경 내용

- AI 모델 목록에 일반 Gemma 4 E4B-IT LiteRT-LM을 추가합니다.
- 기존 E2B 기본형·GPU형의 선택, 다운로드 파일과 캐시를 유지합니다.
- E4B는 별도 파일·캐시를 사용하며, 내려받기와 실제 번역 점검을 통과해야 적용됩니다.
- 사전 저장 공간 가드(`GemmaStoragePolicy`)를 통해 불충분한 공간에서 JNI 네이티브 진입 전 안전하게 사용자 오류로 거부합니다.
- CPU XNNPack 캐시 완료 마커(`cache_completion_marker.json`)를 도입하여 유효한 캐시가 존재할 때 재사용을 보장합니다.
- 외부 모델 카탈로그가 내장 E4B ID나 파일명을 덮어쓰지 못하도록 검사합니다.
- 고정 모델 출처·해시와 Apache-2.0 라이선스 고지를 추가합니다.

## 사용 방법과 저장 공간

설정에서 AI 모델 목록을 열고 원하는 모델을 선택한 뒤 내려받기·점검·적용을 실행합니다.
한 번에 하나의 모델만 실행하며 다른 모델의 다운로드 파일은 보관합니다.
E4B 모델 파일은 약 3.41 GiB (3,659,530,240 B)입니다. 이번 API 35 ARM64 에뮬레이터의 CPU 실행 캐시는
약 2.06 GiB (2,210,334,416 B)였습니다. 캐시 크기는 런타임·실행 환경에 따라 달라질 수 있습니다.
저장 공간 가드 정책:
- 최초 다운로드 시 모델 파일 + 캐시 예산 2,400 MiB + 안전 여유 512 MiB, 약 6.3 GiB의 빈 공간을 확인합니다.
- 런타임 초기화 시 완료 마커가 없을 경우 보수적 캐시 생성 예산 2,400 MiB + 런타임 안전 여유 128 MiB (합계 약 2,528 MiB)를 확인합니다. 이는 물리 실측 크기(약 2,108 MiB)와 구분되는 보수적 운영 정책입니다.
- 초기화 성공 시 atomic 마커가 기록되며, 완성된 캐시가 확인되면 128 MiB의 런타임 안전 여유만으로 즉시 재사용합니다.

## 확인한 범위

API 35 ARM64 전용 에뮬레이터에서 3건의 계측 시험을 개별 검증했습니다:
1. **저공간 사전 거부(Negative)**: 약 515 MiB 여유 공간에서 네이티브 충돌 없이 `IllegalStateException`("저장 공간")으로 거부 및 E2B 유지 확인 (4.228s).
2. **캐시 및 마커 생성(Positive Run 1)**: E4B 모델 초기화 및 번역 시험 문장 `안전하게 대피해 주시기 바랍니다.`에 대해 `Please evacuate safely.` (1,237 ms) 출력, 캐시 및 마커 기록, E2B 복귀(`Hello`) 확인 (36.44s).
3. **완료 마커 기반 캐시 재사용(Positive Run 2)**: 659 MiB 여유 공간에서 캐시 재생성 없이 즉시 로드 후 번역 `Please evacuate safely.` (1,417 ms) 출력 및 E2B 복귀 확인 (17.468s).

패키지 검증:
- 배포 패키지 `MCastTalk-0.2.46-beta.apk` (code 53, SHA-256 `3575b5f40ed10496d0cc1683632ed0b2cd72c2ca3ced5a21d4f2fe636491c5ce`, 96,358,265 bytes).
- 테스트 패키지 `MCastTalk-0.2.46-beta-androidTest-final.apk` (code 0, SHA-256 `1576907e7b778f1004530fd2023166b59bdbd00221448116771fdbb3d02a777b`, 4,796,450 bytes).
- 기기 내 실제 설치된 패키지 해시 비트 단위 일치 확인 (`sha256sum /data/app/.../base.apk`).
- Scheme v3 서명 일치, 16 KiB alignment 통과. 최종 성공 시험 후 수집한 crash logcat 버퍼가 비어 있음을 확인했습니다.
- 전체 단위 시험 1,400건 전건 통과, 린트 0 Error 83 Warning 확인.

## 제한

일반 E4B-IT는 번역 특화 Translate Gemma 4 Sub E4B GGUF 모델과 다릅니다.
GGUF는 이번 APK에서 지원하지 않습니다. 다국어 번역 품질 우위, Galaxy 실기기 GPU 성능,
2초 p95 첫 음성 지연 및 장시간 안정성을 새로 입증한 배포가 아닙니다.
기존 C 버전의 [알려진 제한](RELEASE_0_2_45_BETA_C.md)도 계속 적용됩니다.
모델 추가가 기존 음성 인식·입력 문제의 해결을 의미하지 않습니다.
