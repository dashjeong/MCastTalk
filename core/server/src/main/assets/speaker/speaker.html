브라우저 마이크 보안 준비

모바일 브라우저는 사설 IP의 평문 HTTP에서 마이크를 허용하지 않습니다. 이 송출기에서만 생성한 로컬 CA를 등록한 뒤 같은 /mic 주소의 HTTPS 화면을 여세요.

Android용 CA 인증서 받기 (PEM) Android 대체 형식 받기 (DER) iPhone용 보안 프로파일 받기
다운로드 인증서의 SHA-256 지문 (DER 기준)

이 인증서는 이 송출기 설치가 만든 사설 로컬 CA이며 공식·공개 신뢰 인증서가 아닙니다. 설치 전에 방송 폰 앱 화면의 SHA-256 지문과 위 다운로드 인증서 지문을 한 글자씩 비교하세요. 다르면 변조되었거나 다른 송출기용일 수 있으므로 설치하지 마세요.

인증서 설치 완료 · 보안 /mic 열기

방송 운영자가 설정한 4~8자리 PIN을 입력하세요.
