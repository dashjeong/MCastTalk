현장 핫스팟 마이크 보안

보안 마이크 인증서 등록

인터넷 없는 현장 핫스팟에서 모바일 브라우저로 마이크를 방송하려면 1회성 인증서 등록이 필요합니다.

  1. CA 인증서 다운로드
    아래 버튼을 눌러 송출기의 로컬 Root CA 인증서를 다운로드합니다.
    인증서 다운로드 (ca.crt)
  2. 기기 보안 설정에서 CA 인증서 설치
    기기 [설정] > [보안 및 개인정보 보호] (또는 생체 인식 및 보안) > [기타 보안 설정] > [인증서 설치] > [CA 인증서]를 차례로 선택합니다.
  3. 다운로드 파일 선택
    경고 팝업이 뜨면 [그래도 설치]를 누른 후, 다운로드 폴더의 guidecast-root-ca.crt 파일을 선택하여 설치를 마칩니다.
💡 인증서 설치는 최초 1회만 진행하면 되며, 등록 후에는 바로 안전하게 마이크를 사용할 수 있습니다.
  1. 보안 프로파일 다운로드 (Safari)
    반드시 Safari 브라우저에서 아래 버튼을 눌러 프로파일을 다운로드합니다.
    프로파일 다운로드 (.mobileconfig)
  2. 프로파일 설치
    다운로드 안내 창에서 [허용]을 누른 뒤, 기기 [설정] > 상단의 [프로파일이 다운로드됨]으로 이동하여 우측 상단의 [설치]를 누릅니다.
  3. 루트 인증서 완전 신뢰 활성화
    기기 [설정] > [일반] > [정보] > 맨 아래 [인증서 신뢰 설정]으로 이동한 뒤, GuideCast Local Root CA 스위치를 [켬]으로 켭니다.
💡 [인증서 신뢰 설정]에서 스위치를 켜야만 Safari가 안전한 HTTPS 연결로 인식하여 마이크를 켭니다.
