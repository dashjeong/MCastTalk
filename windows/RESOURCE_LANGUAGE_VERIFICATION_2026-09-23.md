## 요청 반영

1. 전체 언어 완료를 기다리지 않고 언어별 자막·통역 음성을 전달한다. 짧은 발화의
   ASR 계산량을 조정하고, 번역과 TTS를 겹치며, 첫 발화 전 모델을 준비한다.
2. 이해하지 못하는 언어의 원음은 20%, 통역음은 100%. 기본 청취 언어와 추가 원음
   유지 언어 하나는 원음 100%, 원문 자막으로 듣고 불필요한 번역/TTS를 생략한다.
   참가자가 설정한 발화 언어 기준이며 자동 언어 판별을 보장하지 않는다.
3. 운영자가 회의 언어 **개수와 종류**를 먼저 지정한다. 참가 전 사전 검사 및 실제
   참가/언어 변경 시 원자적 검사로 한도를 적용한다. 기존 참석자를 일부 제외하거나
   통역 수신자를 언어별로 잘라내지 않는다. 잘못된 변경은 기존 설정/접속을 보존한다.
4. 시작 시 네 개의 공개 합성 3초 발화를 실제 모델로 처리해 보수적 권장을 표시한다.
   20% 여유와 VAD/전달 800ms를 반영한다. 최근 8개 처리 관측으로 권장은 갱신하되
   이미 수락한 회의 언어 수를 자동 축소하지 않는다. GPU→CPU 전환 시 재측정을 안내한다.
5. 기본 품질 우선. 권장 초과 시험은 관리자만 명시적으로 지연 위험을 확인해 허용한다.
   운영 정책은 서버 실행 세션 동안 유지되며 재시작 시 재측정/품질 우선으로 돌아간다.
6. 기존 관리형 데이터 폴더의 worker는 새 앱의 SHA 검증된 코드로 실행한다. 기존
   계정·모델·운영 설정을 덮어쓰지 않고, 사용자가 별도로 지정한 worker 경로도 보존한다.

## 성능 판정

- 개발 PC: i7-8850H, 시스템 RAM 16GB, Radeon Pro 560X **4GB VRAM**.
  번역 실행 경로 Vulkan, 해당 브라우저 시험 중 CPU fallback 없음. STT/TTS는 CPU.
- 브라우저 합성 발화 시작→통역 음성 재생: **8,316ms / 11,129ms**.
  입력 발화 길이·캡처가 포함된 수치다.
- 마지막 엔진 요청: ASR 2,843ms, 첫 자막 3,902ms, 첫 음성 5,124ms,
  전체 6,151ms. 이 수치는 브라우저 발화 시작 기준 지연과 다르다.
- 이전 r6 인터넷 차단 VM의 31–33초와 개발 PC의 8–11초는 실행 환경이 다르므로
  동일 환경의 개선 배율로 발표하지 않는다.
- **목표 5초 이내 통역은 이 PC에서 합격하지 못했다.** 초기 보수적 단일 통역 추정도
  약 6.5–7.0초로 목표를 초과했다. 기본 권장은 회의 원음 언어 1개/통역 출력 0개로
  정직하게 안내한다. 네 언어 시험은 명시적 고급 지연 허용 상태에서 수행했다.
- 현재 실제 지원 모델은 한국어/영어/일본어/중국어 **4개**. 5/7/10 선택은 모델 팩
  미설치로 비활성화한다. 일반화된 용량 계산의 가상 10언어 단위시험은 실제 10언어
  STT/MT/TTS 동작이나 실시간 성능 검증이 아니다.
