# MCastTalk 0.4.1 offline development candidate

This is a development acceptance-test build, not a claim of certified or defect-free software.
Machine translation/transcription/speech can be wrong. Verify important content against its source.
No cloud account, remote inference API, runtime model downloader, external STUN or TURN is used.

Download URLs, hashes and sizes are preserved in `assets/download-evidence.json`.
That historical download list also identifies the superseded shared MSVC inference
archives. The **actually shipped** rebuilt executable hashes, pinned source revisions,
and compiler settings are in `assets/native-runtime-evidence.json`.
`manifest.properties` hashes the copied bundle and `asset-hashes.properties` hashes inference assets.
Runtime startup verifies inference asset hashes. A hash is an integrity check, not a code signature.
Distribution signing and comprehensive transitive-native-dependency legal review remain release gates.

## Operating limits

Windows x64. Minimum 8 GiB physical RAM checked at first launch; 16 GiB or more recommended
for evaluation. Reserve at least 12 GiB disk space across installer, application and data folder.
Vulkan startup is attempted; unsupported hardware falls back to CPU. A failed Vulkan translation
request is also retried once on CPU, with the fallback reported. This is not a GPU throughput promise.
STT and TTS currently run on CPU. Keep other heavy GPU/CPU applications closed during evaluation.

At most eight room participants for bounded LAN mesh connections. This is a protocol limit,
not a verified eight-speaker real-time capacity. Use short, sequential utterances on modest hardware.
The queue is bounded; overload and timeouts are reported, not disguised as completed translations.
No external-network NAT traversal, SFU, internet media relay or persistent meeting recording is included.

LAN uses explicit private IPv4 addresses and HTTPS/WSS. Client devices must trust the local
meeting CA after verifying its fingerprint with the operator. Never distribute server.p12 or its password.
The application does not install OS trust or change firewall rules automatically. Use a private-network
firewall rule scoped to the actual LAN subnet. A changed server address requires deliberate certificate renewal.

Transcripts/chat are not persisted by the meeting host. STT temporarily writes short WAV segments
under the workspace; normal completion removes them. Abnormal process termination can leave files
in the owner-restricted `temp/inference` directory. Inspect/clear it when the host is stopped if needed.

Existing user accounts and model settings are not overwritten by bundle setup. Uninstall preserves
the selected MCastTalkData workspace; remove it yourself only after backing up anything you need.
