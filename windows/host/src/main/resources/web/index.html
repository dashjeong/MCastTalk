내 언어 및 오디오 설정

기본 청취 언어와 추가 언어는 통역 없이 정상 음량의 원음·원문 자막으로 전달합니다. 예: 한국어 + 영어. 다른 언어만 번역합니다. 발화자는 실제로 말하는 언어를 따로 선택하세요.

참가자별 표시·청취 언어를 사용합니다. 자동 통역은 짧은 발화 단위로 처리합니다. 모델 미설정 시 원음·원문 채팅만 제공됩니다.

자원 최적화 · 통역 언어 권장

로그인 후 호스트 측정 결과를 확인합니다.

지원 언어 수는 동시 처리 보장이 아닙니다. 권장은 한 명씩 짧게 발화할 때의 통역 출력 언어 수이며 참석자 수와 다릅니다. 기본 청취 언어·추가 원음 유지 언어는 중복 통역에서 제외합니다.

이 모델은 의료 조언·의료 결과 해석, 사법·법집행·이민·망명 처리 용도 등에 이용할 수 없습니다. 회의 참가 전에 조건 전문을 확인하세요.

호스트의 접속 범위와 로컬 모델 설정을 확인 중입니다.

        회의 참석자 초대

        이 PC의 브라우저에서만 사용할 수 있는 링크입니다. 다른 PC·휴대전화에서는 접속할 수 없습니다.

        모든 참가자에게 관리자 발급 계정이 필요합니다. 링크는 회의실 주소이며 권한을 부여하지 않습니다. 현재 읽기 전용 참가자는 원문 채팅을 볼 수 있습니다.

        내 계정

        변경하면 모든 기기의 로그인이 해제됩니다. 새 비밀번호로 다시 로그인하세요.

        계정은 관리자가 발급합니다. 게스트에는 만료 시각과 회의실을 반드시 지정하세요.

        계정 목록

          새 계정 만들기

          기본 기간은 지금부터 24시간입니다. 실제 사용 가능 기간은 서버가 확인합니다.

          계정 수정

          초기화하면 해당 계정의 모든 로그인이 해제됩니다.

          현재 호스트의 실제 상태입니다. 연결 수는 처리 성능 보장이 아니며, JVM 힙은 PC 전체 메모리나 GPU 메모리가 아닙니다.

          자원 최적화 다중언어 설정

          회의에서 사용할 언어 · 모두 해제하면 설정 개수 이내 자동

          이번 서버 실행에만 적용합니다. 재시작하면 다시 측정하고 품질 우선·자동 선택으로 돌아갑니다. 언어를 줄이거나 참가자의 청취·자막 언어를 통일하면 부하가 줄어듭니다.

          기능 준비 상태

            개발 검증 버전입니다. 영상·원음은 LAN 연결, 자동 통역은 구성된 로컬 모델을 사용합니다. 모델 로딩·하드웨어·동시 발화 수에 따라 지연이 발생합니다. 인터넷 NAT 중계와 다른 물리 기기의 수용 시험은 별도 검증이 필요합니다.
