## 수정 사항

- `CODEX-R7-ADMISSION-01`: 한국어/영어를 서로 이해하는 두 참석자가 MT/TTS 수요
  없이도 자원 권장 언어 수 1개 때문에 거부되던 결함을 수정했다.
- 운영자가 정하는 허용 언어 수/종류, 설치 모델 지원 범위, 실제 통역 부하를 분리했다.
  자동 허용 수는 설치 언어 중 최대 5개이며 명시적 수동 한도/목록은 계속 강제한다.
- 품질 우선의 권장 초과 슬롯은 **원음 조건부 허용**이다. 번역이 필요한 참가/변경은
  실측 준비와 예상 부하/메모리 검사를 통과해야 한다. `allow-delay`를 암묵적으로 켜지 않는다.
- 모든 활성 방을 검사하는 정책 변경 및 실패 롤백을 유지한다. 기존 참가자/통역 수신자를
  조용히 제거하지 않는다. 미래의 모든 번역 조합을 언어 슬롯 수만으로 보장하지 않는다.
- 원음/영상은 ASR 준비·자막 지연과 분리한다. 원문 자막의 추정 지연을 별도로 안내한다.
- Antigravity 독립 코드 리뷰가 발견한 발화 언어 허용 목록 경고 누락을 수정했다.
  화면은 번역 대상만이 아니라 input/publish/listen/display 전체 계획을 검사해 경고한다.

## 협업과 검증 방법

Antigravity 공식 CLI `7df87a90-97d2-4ed8-8375-5c32b38192c2` 대화에서 설계 반박/정정을
거쳐 구현 정적 리뷰를 받았다. Antigravity는 소스 수정이나 실행 시험을 하지 않았다.
공유 폴더의 `ANTIGRAVITY_TO_CODEX_2026-09-23.md` 인계도 수신했다.
정적 리뷰 의견을 제품/성능 PASS로 간주하지 않으며 Codex가 실제 시험을 수행한다.

verification 스킬에 따라 언어 선택 → API 사전 검사 → 서버 입장/롤백 → 원음/자막/
통역 재생 경계를 검사한다. agent-browser가 설치되지 않아 기존 Playwright/Edge
시험 도구를 사용한다. 실제 사용자 계정/음성은 사용하지 않고 신규 시험 계정과 합성
음성/카메라를 사용한다.
