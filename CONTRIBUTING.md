# Contributing

For the published package, use the source tag identified in README.md. Build requirements are JDK 17, Android SDK API 36 and the tools declared in Gradle.

Submit concise product bug reports or source changes. State the affected package version, expected behavior and reproduction steps. Do not include credentials, personal recordings, private transcripts or internal development conversations.

First-party source is licensed under Apache 2.0. Preserve required copyright and third-party notices.
